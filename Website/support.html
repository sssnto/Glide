2.0 新工作台

原来的设置、离线和我的片库在哪里？

新版底部是观看、片库、收藏、任务。设置在观看、收藏和任务页右上角，片库的更多菜单也可进入；媒体来源保留在片库左上角。下载和行程进入“任务 → 离线片库”，观看历史在收藏页切换。

怎样开始无需账号的演示？

打开“片库 → 左上角媒体来源 → 离线演示片库”，即可播放应用内原创短片。无需登录、连接 NAS 或下载第三方视频。

开始使用

如何播放本地视频？

在片库打开媒体来源，选择“导入视频文件”或“添加本地目录”。导入会复制文件，添加目录会保存授权并保留视频原位置。iCloud 或其他文件提供方的可用性由该服务管理。

Glide 提供影视资源或在线字幕搜索吗？

Glide 不提供影视片源，也没有在线字幕搜索服务。请使用你有权访问的视频、媒体服务器和字幕文件。

服务器与 NAS

如何连接 Jellyfin 或 Emby？

在媒体来源添加服务器地址与对应账号。手机需要能访问该地址；局域网连接需允许本地网络权限。支持反向代理的路径前缀。Jellyfin 和 Emby 均已支持。

SMB 和 WebDAV 连接失败怎么办？

确认手机与 NAS 的网络、协议、端口、账号权限，以及 SMB 共享目录或 WebDAV 路径。先测试连接；如果使用 VPN，确认其允许局域网访问。SMB 2/3 需手动填写共享目录，当前不自动发现服务器或枚举共享。

为什么有的媒体不能下载离线？

离线下载有来源和文件类型限制，当前媒体服务器下载沿用可支持的 MP4／MOV／M4V 原文件范围。下载完成也不保证设备支持该视频编码。请以视频详情页实际可用操作为准。

方向保存与任务

如何在原列表批量旋转？

在符合条件的 Jellyfin 视频网格点“选择”或更多菜单的“批量旋转”，对照当前预览勾选，选择方向后提交。“全选已加载”只选择当前已加载内容，不会为了选择而扫描整个服务器。进度在任务页查看，可进入详情暂停后续、继续或核对。

Jellyfin 大视频会传到手机处理吗？

配套插件在 Jellyfin 服务器处理，手机只提交和查询任务。需要安装匹配服务器版本的 Glide Toolkit 1.1.0 或更新版本、授予用户权限，并保证媒体目录可写。现有安装包面向 Jellyfin 12.2 的 Linux／NAS Docker 环境，见插件说明。

如何从 Jellyfin 插件存储库安装？

管理员打开 Jellyfin 控制台 → 插件 → 存储库 → 添加，名称填写 Glide Toolkit，URL 使用下面的完整地址。保存后回到插件目录安装 Glide Video Toolkit，再重启 Jellyfin。目前安装包为 1.1.1.0，面向 Jellyfin 12.2 的 Linux／NAS Docker 环境。

https://raw.githubusercontent.com/sssnto/GlideToolkit/main/manifest.json

从旧版手动包迁移时，先等当前任务完成，再主动在目录选择新版安装；保留配置、任务记录和备份。安装和更新说明见独立插件仓库。

WebDAV 保存方向有什么条件？

WebDAV 需要可写目录、安全替换检查，以及足够的设备和服务器空间。客户端下载当前原文件、修正方向后回传，并保留备份。文件越大，需要的时间与空间越多；有配套插件时，大视频可选择 Jellyfin 的服务器处理方式。

为什么没有保存或重试按钮？

目前方向保存覆盖符合条件的 MP4／MOV／M4V；SMB、Emby 或权限不足的来源不提供相同保存操作。若任务显示需核对，不应重复旋转，请先按任务详情核对并保留备份。保存与还原只在你主动确认时发起。

方向已保存，封面或服务器还没有变化？

Glide 会更新方向状态与预览。Jellyfin 媒体索引或其他客户端的旧缓存可能仍需刷新；服务器目录中的新文件也需要已加入媒体库并完成扫描，才能在 Jellyfin 中出现。

播放与缓冲

原画黑屏、有声音或一直缓冲怎么办？

先确认网络与服务器状态，在播放设置查看自动播放和可用的原画兼容操作。本地或已下载文件可尝试“兼容播放 · VLC”。服务器的 HLS／转码路线还依赖对应权限与处理能力。切换后的效果以实际文件为准。

下载后流畅，在线播放却卡顿？

这有助于区分文件解码与网络供流问题。请记录卡顿时间、网络关系、所用路线，以及是否连同声音一起停顿；在应用内预览并分享脱敏播放诊断，不必提供原视频或登录信息。

兼容播放支持 PiP 和 AirPlay 吗？

画中画与 AirPlay 请使用相应可用的系统播放路线。兼容播放与应用自行绘制的外部字幕层有输出限制，不能假定与手机内播放完全一致。

音轨与字幕

字幕没有显示，或者无法选择多个字幕？

先在播放器的字幕入口检查所选轨道与关闭状态。新版可显示服务器完整轨道列表，并支持同名外挂、字幕导入与两路外部字幕。请同时确认字幕格式、来源与应用版本，不同路线的能力不同。

ASS 原字体、颜色或特效不正确？

应用使用原始 ASS／SSA 脚本渲染。要使用原字体，需要视频附件、脚本内嵌字体或实际导入对应字体；缺失时会提示。可在“字幕控制 → 导入字幕字体”选择 TTF、OTF 或 TTC。普通字幕外观设置不覆盖 ASS 原样布局。

PGS、双字幕与字幕全文有哪些区别？

PGS 是图形字幕，Jellyfin 客户端显示需要服务器能提取原始字幕。双字幕先覆盖应用可读取的外部字幕；字幕全文与台词搜索依赖可读取的文本，不会从图形或烧录字幕自动识别文字。外部叠加字幕只显示在应用内画面。

如何在播放中切换音轨？

在播放器底部音轨入口选择可用轨道。服务器播放可能需要重新建立对应音轨的流，应用会保留当前进度与播放状态。若列表为空，请附应用版本、来源类型和脱敏诊断反馈。

频道与内容地图

私人频道是 IPTV 或直播服务吗？

不是。它将你已有来源中的内容按规则编排到一起；剧集按季集顺序，普通视频可排除已看完与最近开播的内容。不连接第三方直播频道，也不提供直播内容。

为什么内容地图提示不可用？

本地与离线文件需要系统能解码取帧；Jellyfin 需要已生成当前文件版本的 Trickplay。SMB、WebDAV 或其他来源不会为此下载整片生成地图，可按实际能力使用章节与时刻。内容地图不包含剧情、人物识别或自然语言画面搜索。
