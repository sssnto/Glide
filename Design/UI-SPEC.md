# Glide · Quiet Cinema 设计规范

版本 01 / 2026-09-20 / 供原生实现评审

> 此文档保留初版原型决策。当前原生应用的信息架构与收费状态以 [2026-09-23 全局改版](../Docs/UI-Redesign-2026-09-23.md) 为准；下文 Pro 入口为旧方案，当前应用不展示。

## 视觉目标

高级感来自真实内容、准确层级和稳定交互。主界面采用沉静的影院深色，少量雾绿只用于主要动作、选中状态与播放进度。减少纯装饰卡片、渐变、营销标语与重复计数。交互原型中外围介绍与编号属于评审环境，不进入实际 App。

## 页面结构

### 片库总览

顶部 Glide + 来源入口；大标题“你的片库”，轻量连接标签；一张继续观看卡片，明确剩余时间；媒体库入口；最近加入。无播放记录时不占用继续观看区域。多个来源通过弹出列表选择，来源失联时保留缓存封面并显示“离线”，不阻断其他来源。

首次无来源：以“连接你的私人影院”为主动作、“体验演示”为次动作。只在首次体验展示简短说明，不让登录成为使用离线演示的前提。

### 目录与视频平铺

面包屑 → 目录标题/收藏目录 → 当前范围计数 → 横向文件夹条 → 范围内搜索 → 全部视频/范围切换 → 顺序随机/刷本目录 → 视频网格。

iPhone 默认双列，iPad 自适应3–5列；海报2:3，截图16:9。标题最多两行，年份/时长按媒体类型选择。缩略图失败使用固定比例的低对比占位，保留片名。文件夹入口显示直接子目录；视频网格默认包含全部后代。范围切换同时更新计数、搜索结果和开刷队列。

商业版全范围搜索需服务端查询或索引支持；不能拿当前已加载封面过滤冒充全量搜索。搜索与排序状态随目录记忆。进入子目录滚动到顶部，返回恢复上级位置。刷新时保留旧内容与位置，以小型顶部进度提示更新，失败不清空已有内容。

长按视频显示详情、收藏、下载（Pro）、标记已看；直接点封面开始观看。长按与下载菜单属于后续原生能力，当前网页原型仅演示点选播放。

### 沉浸播放

黑底，默认适应画面，不裁切横屏内容。顶部返回、当前目录/队列位置、更多；底部片名、进度条、播放暂停/前后、收藏、旋转。选中画质与实际播放状态分别展示。点空白显隐控制，操作后3秒无活动可隐藏，拖动/加载/错误时不隐藏。

左右切片需方向锁与最小位移阈值；切换片名、画面、队列索引同步更新。双指缩放不触发切片，放大后双指平移受边界约束。系统边缘返回、进度拖动和画面手势互不抢占。辅助功能用户可用明确的上/下一片按钮，VoiceOver朗读片名、索引和播放状态。

横屏是真正的 UIWindowScene 方向变化；按钮图标表达目标方向。退出还原进入前方向。iPad 分屏下尊重系统可用方向。网页中的“横屏预览”只是切换宽设备布局，并非实际系统旋转。

画质选择为底部面板：自动、原画、1080p；副文案说明清晰度/网络取舍。选中显示勾选，关闭后回到原进度。转码不可用时禁用并说明服务器权限或兼容性原因；不要笼统显示“Pro解锁”。字幕/音轨、速度、睡眠定时等后续归入同一更多面板的独立分组。

### 来源连接

先协议后表单。Jellyfin：地址、用户名、密码；WebDAV同样字段但提示目录地址。输入内容不进入遥测。连接中按钮防重复提交，可取消。成功进入媒体库选择。错误区分地址格式、网络超时、证书问题、认证失败和无媒体库权限；给出就地修复方式，保留非敏感输入。不会默默忽略证书校验。

### Pro 与离线

从设置或主动点击Pro能力进入，关闭按钮始终可见。展示已交付能力、总价、一次购买、恢复购买。价格从 StoreKit 加载；加载失败显示重试，不能拿占位金额发起购买。付款中/待批准/成功/取消/失败/已恢复各有清楚状态。

离线页面展示下载中与已下载、可用空间、暂停/继续/移除。首次空状态先解释价值。空间不足时停止新任务，已下载内容保持可用。具体下载与删除确认设计随 P1 实现补齐。

## 状态规范与文案

| 状态 | 展示 | 可执行动作 |
|---|---|---|
| 首批加载 | 与网格等比例骨架，目录条单独骨架 | 返回/取消 |
| 分页加载 | 网格尾部小进度，不替换现有封面 | 浏览已加载内容 |
| 空目录 | “此范围内还没有视频” | 切换含子目录/返回上级 |
| 搜索无结果 | “没有找到匹配的视频” | 清除条件 |
| 图片失败 | 片名+媒体占位 | 仍可播放 |
| 网络中断 | “连接暂时中断，已保留当前内容” | 重试/离线内容 |
| 令牌过期 | “请重新连接此来源” | 重新登录；其他来源照常可用 |
| 队列准备 | “正在准备…已找到N部”，范围名固定 | 取消 |
| 转码准备 | 小进度及当前请求画质 | 取消并恢复原画质 |
| 不支持直放 | “此格式暂时无法直接播放” | 尝试1080p/查看原因 |
| 最后一片 | “已看完当前范围” | 重新播放/返回目录；不跳到其他目录 |
| 购买待批准 | “购买请求已提交，等待批准” | 关闭返回；权益暂不解锁 |

## iPad 与无障碍

常规宽度左侧190–240 pt来源/导航栏，右侧内容网格；紧凑宽度改为底部导航。播放器移除侧栏以最大化视频，当前网页原型仍保留评审布局。分屏宽度按可用空间而非设备型号决定列数。键盘空格播放、方向键前后/快进需避免与文本输入冲突；字幕对比、Reduce Motion、VoiceOver焦点与大字体需真机验收。

动效150–220ms，淡入/小范围位移；刷片跟随手指位移而不是固定延迟。减少动态效果时禁用位移，保留状态变化。触感仅用于收藏、锁定等确认操作，不在连续拖动中震动。

## 原型说明与已知边界

`index.html`可直接在浏览器打开，素材在assets内，无外部字体或图库依赖。所有片名/数量为演示数据。支持页面切换、目录范围、搜索、选片、随机队列、前后切换、收藏、画质面板、进度滑块和iPad布局。连接表单、购买和恢复购买仅本地演示；不发送密码、不扣款。画面为静态原创照片，非真实视频，双指手势和系统旋转尚未在网页中模拟。

原生已有功能不被此设计稿替换。本规范是实施目标，不等同于现有App全部符合规范。
