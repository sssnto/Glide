## 验证

Chrome 本地浏览器交互检查：目录范围、点选封面、画质面板、收藏操作、下一片、iPad布局和320/390px文档宽度均通过，未捕获JavaScript异常。页面截图另行人工查看；初次发现的脚本全局名称冲突和窄屏按钮换行已修正。

`verify.cjs` 使用 Playwright 与 Chrome。先在本目录执行 `npm install --no-save --package-lock=false playwright`，确保已安装 Chrome，再运行 `node verify.cjs`；也可通过 `NODE_PATH` 使用已有 Playwright。此验证不代表原生播放、真实购买、无障碍或真机性能验收。

## 原生落地进展（2026-09-21）

已开始将设计应用于SwiftUI：更新全局石墨/雾绿配色；压缩片库页顶部；媒体库卡片、横向目录入口、视频平铺、顺序/随机与开刷工具条；来源连接引导和播放器次要文字/点击区域同步调整。当前底部保留真实可用的片库、来源和手势入口。原型中的完整四栏导航、离线下载、Pro及支付仍属于后续规划。

已有搜索仍明确限定“已加载的视频”；全范围搜索与可切换递归范围尚未落地。演示片库继续使用与现有演示视频匹配的插画封面；真实片库展示服务器提供的封面。


## 原生第二阶段（2026-09-21）

全范围搜索、目录内完整收藏筛选、独立“收藏与继续观看”面板和本地持久观看记录已实现。筛选后播放结果使用同一结果集合；可长按封面收藏、左滑移除收藏或记录。递归/仅当前层切换、离线下载和Pro权益仍未实现。个人记录为本机数据，不宣称跨设备同步。

## 原生第三阶段（2026-09-21）

以上“未实现递归切换”的说明为阶段历史，当前已支持目录范围、名称排序、固定目录与按目录保存偏好。原生新增电影海报墙/详情、节目季集列表、声音/字幕/画质选择，并将影视播放与家庭刷片分开。网页原型尚未同步这组新页面；以 SwiftUI 实现和模拟器验证为准。照片查看、下载及 Pro 支付仍属后续能力。

原生界面截图（本地虚构测试媒体）：[电影详情](native-movie-details.png)、[节目季集](native-show-seasons.png)。已检查声音/字幕标签、海报裁切与季集排序；海报点击区域限制在卡片内。

演职人员新增横向头像卡片和独立相关媒体页：[人员卡片](native-cast.png)、[相关媒体](native-person-media.png)。截图使用本地虚构测试记录，风景图仅验证头像加载；真实使用展示 Jellyfin 人员照片。


## 测试反馈修订（2026-09-21）

原生新增统一 2:3 海报卡片、评分角标、对齐的双行标题；单集详情改为横向剧照。音轨/字幕摘要单行省略，独立选择页完整显示长名称。人员作品只显示电影/节目入口；媒体库增加排序菜单与渐进加载。底部提供真实离线下载管理，支持默认 MP4/MOV/M4V 原文件。上述改动已落地 SwiftUI，网页原型未同步；此前“无下载”的描述为阶段历史。Pro 购买、照片查看与全格式离线解码尚未实现。

已验证的原生布局：[长音轨与字幕名称](native-track-layout.png)。
