## 打开运行

1. 运行 `python3 Scripts/prepare_compatibility_sdk.py` 准备固定 SDK；用 Xcode 打开现有 `Glide.xcodeproj`，选择 `Glide` scheme。无需执行 `pod install`。独立真机验证可选 `GlideCompatibilityQA`，与正式应用并存。

2. 选择 iPhone 或 iPad 模拟器并运行。内置 3 段原创、无网络依赖的动态风景演示视频。
3. 真机运行时，在 Signing & Capabilities 中选择自己的开发团队。
4. 点击片库右上角的来源按钮，选择导入视频、添加本地目录，或通过「添加媒体源」连接服务器。

SDK 准备保留官方 dSYM，并核对各 CPU 架构的 UUID；旧的无符号缓存再次执行准备脚本会自动升级。分发前运行 `python3 Scripts/release_preflight.py --archive "/绝对路径/Glide.xcarchive"`，检查实际归档中应用与内嵌 framework 的符号是否齐全。

准备脚本也会规范 MobileVLCKit 的四处公开头文件引用，消除框架头文件使用双引号引入的编译告警；已有 SDK 缓存再次执行脚本即可升级，播放器二进制与 dSYM 保持不变。

### 本地视频

打开「媒体来源」→「导入视频文件」，批量复制到 Glide；重名文件自动编号。也可选择「添加本地目录」，保留文件原位置并保存授权。目录内支持搜索、收藏、固定目录和顺序／随机刷看；重启恢复原位置。拖动本地视频时间轴可查看定位画面。长按导入视频可删除 Glide 内副本，授权目录中的原文件保持只读。

在播放设置的视频信息中可查看本机格式检查，实际出画面才表示成功播放。「本地播放器」可切换系统／兼容播放；兼容路线已验证 MKV／AVI 和内嵌 ASS 原创样例，仍不承诺全格式。系统文件提供方的长期授权与云端下载仍需真机验收；尚无相册导入。

### Jellyfin

填写例如 `http://192.168.1.10:8096` 的服务器地址及用户名、密码。也支持 `https://example.com/jellyfin` 这样的反向代理前缀。手机需要能访问该地址，局域网连接需允许系统的本地网络权限。

连接后按「服务器 → 媒体库 → 目录 → 视频」管理。首页列出媒体库，进入后逐层浏览普通目录或剧集／季；当前位置提供面包屑和返回上一级。点击「刷新本目录」或下拉刷新重新读取当前层的目录列表和包含子目录的视频封面。任意媒体库或目录都可以点击「刷本目录」：收集该目录及所有子目录的视频，不进入其他媒体库或同级目录。每个服务器记住上次访问的位置。

通过用户账号认证获取 token；使用媒体库分页、PlaybackInfo 设备能力协商、播放会话和进度接口。播放器自动优先尝试系统兼容的原画；画面无法解码或网络持续缓冲时，自动尝试兼容流及 Jellyfin 的 1080p／720p H.264/AAC HLS，不要求用户选择画质。实际转码能力受 Jellyfin 权限、FFmpeg 配置及服务器性能影响。

### NAS · SMB（1.5.0 开发版本）

在媒体来源中选择 SMB，填写服务器和共享目录；支持账号、服务器允许的访客、域，以及主动要求 SMB 3 加密。可先测试连接，再保存打开。账号密码只保存在设备 Keychain 中；使用只读访问，不提供远端删除或重命名。

媒体与目录复用竖版卡片、搜索、排序、固定目录与连续刷看。支持同名 JPG/PNG 预览和目录封面；没有封面时显示文件占位，不自动刮削影视海报。大目录扫描会显示已找到的视频数量，并可停止。需要续播时，在来源中开启“记住播放进度”；默认保留家庭刷看行为。

SMB 使用已验证的 VLC 兼容播放入口，按需读取并支持定位；格式支持取决于编码与设备，实际验收见 [1.5.0 记录](Docs/Testing/Glide-1.5.0/)。保留当前的音轨、内嵌字幕、倍速等能力；不承诺此入口支持 PiP 或 AirPlay。

### 外挂字幕（1.5.1 开发版本）

播放本地目录或 SMB 视频时，识别同目录准确同名及带常见语言后缀的 UTF-8 SRT／VTT／ASS／SSA。唯一候选自动使用；多个候选仅在字幕语言偏好唯一命中时自动选择，也可从播放器字幕菜单手动选择。全局字幕关闭时不自动匹配。

按视频保存字幕选择、关闭状态和外挂字幕延迟。手动导入保留本机副本，关闭后可从字幕菜单重新启用；播放设置可清除当前视频的字幕记忆。字幕变化或丢失、视频大小或修改时间变化时提示重新选择。WebDAV／Emby 可手动导入；Jellyfin 流式播放可读取所选文字字幕，由客户端显示。1.9.0（3）恢复播放中的完整服务器字幕列表，文字切换保留视频会话，手动选择的轨道及偏移记在本机，服务器文字正文仅保留在当前会话内存。文字单个文件上限 2 MB；1.9.0（4）新增 Jellyfin PGS 原始图形字幕提取与客户端叠加，压缩文件上限 64 MB，按当前时间解码图像，保留原始位置、透明度和时间偏移；不通过 OCR 转成台词全文。服务器必须能提取该轨道，失败时保留当前字幕并提示。客户端叠加仅显示在应用内画面。

### ASS／SSA 原样字幕（1.11.0 构建 3）

Jellyfin 的 ASS／SSA 使用原始 `.ass` 数据及当前媒体版本字体附件，不再以 SRT 转换结果作为画面。外挂与手动导入也支持 UTF-8 ASS／SSA。libass 绘制字体、颜色、描边、阴影、定位、绘图、淡入淡出、移动、旋转、裁剪、变换与卡拉 OK；原脚本保留，全文使用独立正文索引。

优先使用字幕内字体、视频字体附件和系统字体；原字体未提供时提示替代，可在“字幕控制 → 导入字幕字体”导入 TTF／OTF／TTC。普通字幕外观设置不覆盖 ASS。字幕脚本上限 2 MB，单个字体 20 MB、字体总量 64 MB；ASS 仅叠加在应用内视频画面，不包含 PiP／AirPlay 字幕输出。新增代码和原创验证已完成，实体机更新与指定剧集复核待设备重新连接。见[结果与边界](Docs/Testing/Glide-1.11.0-ASSStyle-2026-10-22/README.md)。

### NAS · WebDAV

在 NAS 中启用 WebDAV，填写视频目录地址，例如 `https://nas.example.com:5006/video/`。通过 PROPFIND 浏览目录，使用带认证的 HTTP Range 流式播放，不预下载整部影片。支持 Basic 认证；远程使用 HTTPS，HTTP 仅用于可信局域网。1.5.0 开发版本另支持 SMB 直连；NFS 未接入。

WebDAV 直连受 AVFoundation 格式支持限制，优先使用 MP4 / M4V / MOV。MKV、AVI 或不兼容音视频编码建议使用 SMB 兼容播放，或交给 Jellyfin 转码。WebDAV 服务器需要支持字节范围请求。不绕过 TLS 证书验证。

### 链接与片头片尾（1.6.0 开发版本）

片库顶部的链接按钮或媒体来源中的「链接与 STRM」打开独立列表。保存 HTTP(S) 地址、名称与可选请求头，支持编辑、删除、继续观看及字幕导入。STRM 手动导入接受 64 KiB 以内 UTF-8 文件，每个文件一条绝对 HTTP(S) 地址。完整地址和请求头保存到本机钥匙串；系统播放支持取决于编码与设备，带请求头的 HLS 暂不支持。

播放设置顶部的「片头片尾」可设置每视频的片头秒数和片尾倒数秒数，Jellyfin／Emby 剧集可应用到整个节目。默认显示跳过按钮；自动跳过需主动启用，暂停和回拖不反复跳过。Jellyfin 提供真实 MediaSegments 标记时显示相应入口，缺少标记不影响播放。[1.6.0 计划](Docs/Glide-1.6.0-Product-Plan-2026-10-20.md)、[开发验收](Docs/Testing/Glide-1.6.0/README.md)、[发布说明](Docs/Glide-1.6.0-Release-Notes.md)。

### 字幕导航与片段循环（1.9.0 开发版本）

字幕控制页新增主字幕全文、台词搜索、当前句跟随与点击定位；定位计算已设置的字幕偏移。单句重播从句首播放，到句尾暂停。A–B 循环支持当前点标记、倍速和暂停，循环时暂挂自动跳过与下一条，手动定位到区间外或切换视频时清除。VLC 在文件结尾通过重新打开同一视频回到 A 点，存在加载间隔，不是逐帧无缝循环。

两路外部字幕分别调整字号、颜色和描边，共用背景透明度，预览与实际字幕使用同一绘制组件，自动保存并支持恢复默认。[1.9.0 计划](Docs/Glide-1.9.0-Product-Plan-2026-10-20.md)、[开发验收](Docs/Testing/Glide-1.9.0/README.md)、[体验步骤](Docs/Testing/Glide-1.9.0/User-Acceptance.md)。全文索引覆盖客户端可读取的文字字幕，1.11.0（3）另支持原始 ASS／SSA 的正文索引；ASS 画面保持原样，不套用普通字幕样式。不包含内嵌／图形／烧录字幕全文提取。

### 双字幕（1.8.0 开发版本）

播放页底部“字幕 → 字幕控制与双字幕”可同时使用两份外部 UTF-8 SRT／VTT。主字幕在上，第二字幕在下，各自保存选择、关闭状态与时间偏移；支持 0.1 秒微调、归零及第二字幕字号调整。第二字幕默认关闭，按需选择同目录字幕或导入受管理副本。旧版本主字幕记忆保留。

两路使用播放器的同一媒体时钟；选择内嵌字幕时使用单字幕模式。1.8.0 历史范围不包含外挂 ASS；1.11.0（3）已加入原始 ASS／SSA 导入与同目录读取。当前仍不包含双内嵌、在线字幕搜索或 PiP／AirPlay 外部字幕输出。Plex 与飞牛按用户决定暂缓；[范围与验收](Docs/Glide-1.8.0-Product-Plan-2026-10-20.md)。

### Emby（1.7.0 开发版本）

媒体来源 → 添加媒体源 → Emby，填写服务器地址、用户名与密码。支持路径前缀，例如 /emby。浏览电影、节目／季／集、家庭视频目录，使用范围搜索、分页、收藏、原文件播放、服务器 HLS 与观看进度同步；复用默认媒体版本的 MP4／MOV／M4V 原文件下载和手动字幕、节目跳过规则。

Emby HLS 出现超出容差的定位偏差时，若同一原文件此前已成功出画面且不依赖服务器选轨，可自动切回原文件恢复位置。测试期间的长 GOP 偏差与新建媒体记录复测结果分别保留，不承诺所有服务端索引与影片组合均适用。服务端与设备实测范围、Plex／飞牛等后续边界见 [1.7.0 计划](Docs/Glide-1.7.0-Product-Plan-2026-10-20.md)、[验收](Docs/Testing/Glide-1.7.0/README.md)和[发布材料](Docs/Glide-1.7.0-Release-Notes.md)。

## 播放范围与顺序

- 文件夹入口保持逐层结构，视频封面平铺包含子目录；开刷时单独收集选中目录的全部后代视频。父目录本身没有视频也能开刷。
- Jellyfin 使用固定 `ParentId` 的递归视频查询，读取所有分页；WebDAV 在所选目录边界内遍历子目录并防止重复访问。
- 准备队列时显示已找到的视频数量，可随时取消；遇到读取失败会提示重试，不把不完整的集合当成完整随机队列。
- 「顺序播放」按当前目录保存的视频排序（名称或添加时间等）播放。「随机播放」将收集完成的整个范围队列打乱，一轮内不重复。
- 视频结束自动播放队列下一部，末尾停止；上滑／下滑及上一部／下一部按钮使用相同的队列顺序。随机模式返回上一部会沿观看历史返回。
- 目录页和播放器内均可切换播放模式，设置会记住。播放中切换模式保留当前视频和播放位置，重新排列后续队列；切换到随机模式视为新的一轮。
- 点击具体视频时先播放该视频；如果启用搜索／收藏过滤，递归收集的播放队列也应用该过滤。「刷本目录」入口播放完整目录范围。

## 屏幕旋转与画质

播放器下方的「横屏／竖屏」按钮可直接切换显示方向，也支持设备自动旋转。离开播放器时恢复进入前的屏幕方向。

Jellyfin 播放会先尝试原画；遇到解码失败或持续缓冲时自动恢复，并在必要时使用最高 1080p 或 720p 的 H.264/AAC 转码。恢复保留当前播放时间和播放／暂停意图。服务器必须允许转码并配置可用的 FFmpeg；WebDAV 没有服务器转码兜底；Jellyfin 下载文件若无法由系统播放，会尝试联网获取兼容流，离线时需要系统兼容的文件。底座选型见 [原生播放器方案](Docs/Player-Engine-Decision.md)。

首帧后的普通缓冲恢复会保留当前流，不因已结束的长缓冲或多次短缓冲立即转码。持续停止播放至少 45 秒且当前位置的连续可用缓存至少 20 秒未增长时才触发缓冲恢复；缓存仍增长时延长等待，最长连续停止 90 秒后恢复。播放重新开始、暂停及定位期间清除本次卡顿观察；真正的解码失败、黑屏和色彩不兼容仍保留自动恢复。

## 交互

| 操作 | 行为 |
| --- | --- |
| 单指上滑 / 下滑 | 下一部 / 上一部，不循环越界 |
| 单指右滑 / 左滑 | 2× / 正常速度 |
| 长按画面左侧 / 右侧 | 快退 / 快进设置的秒数 |
| 双指捏合 | 1–4 倍缩放，切片后复位 |
| 放大后单指／双指拖动 | 上下左右移动画面，恢复原大小后恢复切片／倍速手势 |
| 单击画面 | 显示 / 隐藏控件 |
| 双指轻点 | 播放 / 暂停 |
| 锁定按钮 | 锁定手势；单击画面后可解锁 |

提供显式的上一部、下一部、播放、暂停按钮和可拖动的进度条。播放器支持横竖屏、倍速、适应／填满、视频信息、完整的 Jellyfin／Emby 服务器字幕与音轨列表；切换服务器音轨重新协商同一媒体版本并保留当前进度、播放或暂停状态和字幕选择。刷看模式默认从头播放，不写入观看历史；SMB／WebDAV 来源可自行开启本机进度记忆。电影与剧集详情播放保留续播和 Jellyfin 进度同步。进入后台暂停。

Jellyfin 与 WebDAV 使用系统播放器，本地文件可选系统或 VLC，SMB 使用 VLC。系统播放器的初始远程缓冲目标为 2 秒，出首帧后普通速度目标为 30 秒、2× 目标为 60 秒；正常播放中发生至少 1.5 秒的缓冲等待后，目标提高至 45 秒、2× 至 90 秒，最高 90 秒。目标是系统缓冲偏好，不代表实际缓存保证；持续带宽不足或服务器转码速度不足仍需兼容恢复。通过 AVPlayerLayer 的可显示状态识别首帧；连续拖动仅接受最后一次定位结果，允许小幅时间容差降低解码等待。画中画、AirPlay、字幕及音轨选择均使用系统能力；影视详情另提供 Jellyfin 版本、声音与字幕选择。SMB 的兼容入口能力另见上文；HDR / Dolby Vision 的显示能力取决于设备、源格式及系统支持。自动 HLS 优先协商 fMP4 内可用的原生视频码流；H.264 编码目标明确为 SDR／8-bit，HDR 来源不通过展开主播放列表绕过系统验证。HDR 转为 SDR 仍需要服务器能正确进行色调映射。

播放设置 → 视频信息显示当前媒体版本的源文件路径，支持完整换行、选择和复制；SMB／WebDAV 显示文件位置，离线影片显示本机文件路径。Jellyfin 未返回路径时明确提示，不将带令牌的播放接口地址当作文件路径。远程播放另显示当前位置向前连续已缓冲的秒数；播放诊断 schema 5 包含目标与实际缓冲时长，文件路径仅在信息页显示，不加入诊断导出。

## 安全与数据

- Jellyfin token、SMB / WebDAV 密码保存在系统钥匙串；不把密码存入偏好设置。
- 来源、目录设置、收藏和播放进度保存在带备份的本机快照；旧版 UserDefaults 记录迁移后保留，轻量设置继续使用 UserDefaults。本地目录授权保存在设备内，视频身份使用相对路径。
- 无分析 SDK、广告和第三方同步。
- 前台 API / WebDAV 请求拒绝跨来源重定向；后台下载使用系统 URLSession 的重定向策略。
- 为兼容用户自建局域网 HTTP 服务配置了 ATS 例外；公网推荐 HTTPS。
- 服务器移除时删除对应钥匙串凭据。

## 设计参考

手势参考 [Infuse 播放控制](https://support.firecore.com/hc/en-us/articles/215090987-Playback-Controls)：单击优先唤出控制，长按画面左右侧跳转，双指轻点暂停，以纵向单指滑动刷片。界面、名称和演示素材为本项目独立实现。

### 文件夹与视频平铺

进入家庭视频媒体库或任意目录后，默认显示「媒体」，顶部可切换「目录」。目录与视频均使用 2:3 竖版预览，可按名称或添加时间排序，支持当前范围及所有子目录的视频平铺与渐进加载。SMB 与 WebDAV 复用这套浏览方式，读取时间取决于目录数量。搜索和收藏筛选覆盖所选范围并读取完整结果分页；筛选时“播放结果”使用该结果集合，未筛选时“刷本目录”使用完整目录队列。


### 收藏与继续观看

底部“继续与收藏”打开独立的个人片库，可切换“继续观看”和“我的收藏”。播放时点亮爱心或长按封面可以收藏，左滑条目可取消收藏或移除观看记录。电影、剧集详情播放产生的观看记录跨 App 重启保留；目录刷看不产生观看记录。继续观看的剧集按节目合并入口，最近集未完成时续播，完成时指向下一未看集；播放首帧后补齐集数队列。电影单片续播，目录开刷连续播放选定范围。

记录保存在本设备，保留最近200条历史和全部收藏；删除媒体源同时删除已收录的对应个人记录。旧版仅保存收藏ID，浏览原目录后会补齐可展示的元数据。移除历史只隐藏记录，不清除服务器进度；再次观看会重新加入历史。

搜索在当前目录范围内防抖执行，切换范围/关键词会取消旧任务。Jellyfin使用服务端SearchTerm与固定ParentId；WebDAV遍历当前范围后按标题匹配。结果准备中显示已读取数量，可返回目录或清除搜索停止；大范围收藏筛选需要读取该范围全部元数据，耗时取决于服务器和目录大小。

### 按媒体类型观看（2026-09-21）

Jellyfin 的 `movies` 媒体库显示电影海报墙，点进详情可查看简介、年份、分级、评分、类型、片长和演职人员（依服务器元数据），选择版本、声音和字幕后播放。`tvshows` 媒体库按节目 → 季 → 集展开；季与集使用数字排序，特别篇为第 0 季。电影单片播放；剧集按季集顺序播放，上滑下一集、下滑上一集，支持跨季切换，控制台「选集」可按季选择，首末集不循环。放大后滑动仍用于拖动画面，锁定时不切集。家庭视频继续采用目录、递归范围、顺序/随机和刷片交互。照片混排及照片查看器尚未实现。

指定服务器音轨/字幕时向 PlaybackInfo 传递版本 ID 和实际轨道编号，字幕可交由服务器烧录；原画直放保留播放器内系统支持的内嵌轨道选择。下一集重置文件级轨道编号，并按应用语言偏好匹配可用轨道；无偏好时使用服务器默认设置，不沿用上一集索引。字幕烧录和特殊音频的真实兼容性仍需服务器与真机验证。

目录偏好支持包含子目录/仅当前层、名称升降序和固定目录，并按目录持久保存；列表、搜索及播放队列共用范围和排序。

演职人员现支持头像卡片（姓名、角色/职务）和点击查看相关媒体。相关媒体按人员 ID 查询当前服务器内账号可访问的电影、节目及视频，分页加载；点击作品继续进入现有媒体详情。没有头像显示占位图；缺少人员 ID 的旧元数据只展示卡片，不按姓名模糊匹配作品。


### 测试反馈修订：缓存、排序与离线下载

- 海报墙使用 LazyVGrid 和分批加载；支持名称、评分、发行年份、添加时间、片长及升降序，按媒体库记住选择。搜索和排序由 Jellyfin 执行。
- 详情中的声音/字幕显示单行摘要，点击后在独立列表中查看完整名称并选择，避免长名称挤压重叠。单集使用横向剧照；人员作品页查询电影和节目入口，不平铺单集。
- 元数据缓存 15 分钟，海报磁盘缓存 7 天，合并重复请求；缓存按服务器和账号隔离，总磁盘上限 256 MB。下拉刷新重新请求元数据；删除来源时清理缓存。海报由服务器提供，缺图显示占位。
- 自动播放尊重 AVPlayer 缓冲等待；黑屏、失败或持续缓冲时有界地尝试兼容流、1080p 与 720p 转码，仍失败则显示错误。设备支持的 HEVC/AV1 硬解能力参与协商，不能保证所有设备都能硬解所有 4K/HDR/Dolby Vision 文件。
- 影视详情可下载默认版本的 MP4/MOV/M4V 原文件，底部“下载”管理进度、删除并本地播放。系统后台 URLSession 负责传输，Background Tasks 维护任务状态；系统调度和用户强制退出会影响后台任务。支持暂停／继续有效后台任务，失效任务会提示重新下载；尚不支持 MKV 离线解码、转码 HLS 离线打包和非默认版本下载。


### 标签与相似推荐

影视详情支持点击 Jellyfin 类型与标签，在当前服务器的账号可见范围内查找同类作品，结果分页显示。详情底部显示 Jellyfin 相似推荐；单集以所属节目查询，并将推荐中的单集合并为节目入口。没有元数据/推荐时显示空状态，不生成虚构标签。

“收藏与继续观看”支持编辑、左滑和长按删除。删除观看记录保留收藏，取消收藏保留观看记录；操作仅影响本机记录，不删除服务器视频或重置 Jellyfin 进度。

### 阶段一、二测试版（0.2.0）

播放决策新增“原画兼容”：只有 Jellyfin 明确返回视频码流复制的地址才使用。自动画质对媒体信息中 HEVC/MP4 `hev1` 保持谨慎，不盲目直放；无画面时依次尝试保留视频的兼容流与 1080p 兼容转码。播放诊断在播放器右上角菜单和设置中可预览/分享，仅包含技术字段和错误代码，不含片名、URL 或令牌；显示源媒体编码以及播放器观察到的输出尺寸和码率（可用时）。

第二阶段提供按语言选声音/字幕、外部 UTF-8 SRT/VTT 字幕及时间/位置调整、Jellyfin 进度冲突处理、主动从头播与已看标记、重新登录原来源、后台下载暂停/继续/重试/校验、蜂窝与 Wi-Fi 偏好、容量预算、画中画和 AirPlay 入口，并为 iPad 提供媒体库侧栏。外部字幕只叠加在应用画面，画中画和投屏不会带上它。下载任务被系统移除后的“重试”会重新下载，不能保证传输字节断点续传。画中画和 AirPlay 最终效果需用真机、服务器和外部设备验证。
