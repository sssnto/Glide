# Glide 1.12.0（1）：离线随身片库

2026-10-23。本轮功能已实现，最终核心、模拟器回归、Release 归档及符号校验通过；独立 iPhone 验证通过 36 项原创素材检查，用户确认飞行模式下播放、切换、续播与重启均正常。未提交、推送、打标签或上传商店，官网仍为已发布的 1.11.0。

## 实现

- 「离线 → 创建行程包」按观看时间与容量生成待确认候选，支持所选本地／Jellyfin／Emby 范围和私人频道。完整文件计入容量，剩余观看时间计入时长，不猜测未知大小或片长；最多检查前 200 个候选，界面明确提示。
- 连续剧接下来 3／5 集按来源、节目、季集排序；已看完内容不重复加入，不可用的一集保留阻断占位，避免越集。账号或默认原文件版本变化后要求重新确认。
- 支持 MP4／MOV／M4V／MKV 默认原文件。原文件、已选可提取字幕、可获取字体与配套资料持久保存；ASS 保留原始脚本，Jellyfin 可提取的 PGS 保存为原始图形字幕。封面、简介与来源章节供离线使用，缺失资料不伪装为就绪。
- 独立随身片库只读本机文件，不进行服务器认证、远程字幕查询、下一条网络预热、在线队列扩展或联网转码。MKV 默认使用 VLC。删除服务器后仍可使用已完成下载和本机时刻引用。
- 出发前检查静音试播，通过实际画面与时间推进确认解码链路，再检查配套资源。文件大小、修改时间或配套资源版本变化使检查失效；检查不写观看进度。
- 行程包与下载记录使用可恢复快照。暂停／继续有效任务，失效任务明确重试；待完成文件统一保守预留磁盘容量并保留 200 MB 余量。删除包可保留文件，共用资源不重复清理，不删除原始本地或服务器文件。

## 边界

- 本轮的 Jellyfin／Emby 服务是原创合约服务，证明客户端生产链路在这些响应下的行为，不代表已经验收所有真实服务器版本、代理、下载权限或长片。手机真实断网验收只覆盖原创两段视频；未读取私人服务器账号或片源。
- 不包含 NAS 下载、自动补集、跨设备同步、非默认媒体版本、HLS 离线打包。实际解码依赖设备和内核，不承诺全格式或整片无损。
- 配套字幕只保存可读取的已选资源；内嵌轨道随原文件保留。未提供的原字体仍需导入，不保证缺失字体与原样效果一致；客户端叠加字幕不进入 PiP／AirPlay。
- 检查版本以大小、修改时间和资料元数据摘要为依据，不是整文件内容哈希。检查只试播一段，无法证明每个时间点可解码。
- 后台调度与长时间锁屏传输未做完整矩阵验收；有效任务可暂停／继续，任务失效需重下。磁盘预留保守计入完整待完成文件，部分已下载字节可能重复预留，清理或完成任务后可释放预算。
