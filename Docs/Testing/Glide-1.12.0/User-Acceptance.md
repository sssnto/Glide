据此记录：断网播放、两段切换、本机续播与应用重启后播放均经用户确认通过。无线开关与手动过程由用户操作，未把它记为电脑自动观测；自动验证的断网边界另见 [iPhone 合约报告](iPhone-Contract.json)。该人工验收发生在最终磁盘预留、不可用剧集阻断和创建入口触控区域修订之前；这些收尾改动以最终核心／模拟器回归和构建结果为依据，未改写人工测试的时间与覆盖面。

## 使用自己的片库复核

1. 联网进入「离线 → 创建行程包」，选择本地、Jellyfin 或 Emby 内容范围。设置时间和容量，生成候选，确认后准备。
2. 连续剧选择单一节目的范围，启用连续剧打包，选 3 集或 5 集。某集无法获取可靠文件资料时，不越过它打包后续集数。
3. 等待下载完成，进入行程包运行「出发前离线检查」。资料缺失会单独提示，可联网重新准备；检查不写入观看进度。
4. 飞行模式并关闭 Wi-Fi 后，从随身片库播放，验证切集、定位、续播和重启；存在原字体时复核 ASS 原样显示。
5. 两个行程包包含同一视频时，清理其中一个的本机副本，确认另一个仍可播放。授权目录的原文件和服务器文件保持只读。
