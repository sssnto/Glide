# Glide 0.2 阶段一、二用户测试计划

**测试对象**：iPhone / iPad 上的 Glide 0.2.0。开始前请在「设置 → 版本」记录完整版本与构建号；若不是该版本，请以实际安装版本为准记录。当前文档同时供 TestFlight 与 Xcode 安装包测试。每项使用你自己有权访问的媒体，不需要向我们发送原视频、服务器密码或公开完整地址。

**测试目标**：第一阶段验证播放成功、失败恢复和诊断；第二阶段验证续播、字幕/音轨、下载、连接、iPad 及系统行为。Jellyfin 服务器允许的转码、用户权限和网络速度会影响结果，因此记录手机和服务器环境非常重要。

## A. 15 分钟快速冒烟

| 编号 | 操作 | 预期 |
|---|---|---|
| A01 | 进入电影库，打开一部能正常播放的影片 | 海报与详情出现；点击播放后有声音和画面；进度可拖动 |
| A02 | 进入节目，选季与集，播完或跳到接近片尾 | 下一集按季、集顺序出现，不把剧集当刷片视频 |
| A03 | 从家庭视频任意上级目录开刷，左右滑动并切换随机/顺序 | 队列不越出目录；随机一轮不重复；返回上一部正确 |
| A04 | 播放时点右上角“…”；打开字幕、画质、播放诊断 | 菜单可点且停留，不会突然消失；诊断可预览与分享 |
| A05 | 暂停、退出播放、重新进入同一影片 | 本机继续观看位置保留；联网时尽量使用 Jellyfin 最新进度 |
| A06 | 旋转至横屏再返回竖屏；双指缩放和快进 | 画面、控件与手势不重叠，无黑屏或不可点击 |
| A07 | 进入设置，查看声音/字幕、下载与存储、版本 | 各页完整显示；没有超出屏幕或重叠文字 |

A01、A04、A05 任一失败即停止扩展格式测试，先反馈该阻断问题。

## B. 播放兼容与诊断

| 编号 | 操作 | 预期 | 重点记录 |
|---|---|---|---|
| B01 | 用你截图中的 `HEVC Main 10 / hev1 / 3840×2160` 视频，先选“原画直放” | 如果设备无法显示，约 10 秒内明确报错；不应无限有声黑屏 | 首帧/声音/实际方式；诊断中的 CodecTag、Profile、错误代码 |
| B02 | 同一影片选“自动” | 能播优先；若无法直放，先尝试保留视频码流的兼容流，服务器不明确支持时继续回退到 1080p；不死循环 | 是否出现图像、实际方式、首帧秒数、恢复次数 |
| B03 | 同一影片手动选“原画兼容” | 仅在 Jellyfin 明确给出视频复制流时播放；无法保证时给出说明 | Jellyfin 的转码日志是否写了视频复制（如 `-c:v copy`） |
| B04 | 同一影片手动选“1080p 转码” | 有图像、可拖动进度、字幕和声音可选；显示“视频转码” | 实际分辨率、卡顿与发热 |
| B05 | 测 H.264 MP4、HEVC `hvc1`、HEVC `hev1`、MKV、HDR/杜比视界各一部（有则测） | 能支持的成功播；不能支持的有可解释提示和可用替代 | 每部的编码、容器、位深、画质选项、实际播放方式 |
| B06 | 在播放中切断 Wi-Fi 15 秒并恢复；再次在弱网下重复 | 缓冲提示/可恢复；长期失败有重试或切画质入口，不会不停转码 | 发生时刻、错误状态、恢复所需时间 |
| B07 | 禁用当前 Jellyfin 用户的转码权限后播放不兼容片（方便时测试） | 不承诺转码成功；给出权限/服务器能力说明 | 是否清楚知道下一步 |
| B08 | 播放正常片 30 分钟，并连续切片 30 次 | 无崩溃、持续黑屏、明显内存/温度异常；进度与队列正确 | 首帧 P95 可粗记每次等待，卡顿次数 |

**诊断如何反馈**：出问题时点“…”→“播放诊断”→“分享诊断”，发送前先预览，确认不含私人信息。另附问题发生时的画面截图。诊断目前捕捉首帧、缓冲、协商到的媒体信息及错误域；它没有像素检测，影片本身故意为黑画面时不能凭诊断判定故障。若看不到“播放诊断”，请写明版本/构建号。

## C. 续播、声音与字幕

| 编号 | 操作 | 预期 |
|---|---|---|
| C01 | 手机看电影约 3 分钟后退出，在同一设备重新进入 | 从接近上次位置继续；主动“从头播放”从 0 开始 |
| C02 | 在 Jellyfin Web/另一设备观看同一影片更远位置，再回 Glide；反向再试 | 已同步的服务器新进度生效；刚看完但尚未上传的本机进度不会被较旧的服务器数据覆盖。记录两端时间以判断冲突 |
| C03 | 播到片尾；在详情标记“已看/未看” | 播完不进入“继续观看”；标记与刷新后状态一致，不删影片 |
| C04 | 在“设置”把首选声音设英语、字幕设中文，再连续播两集 | 每集按语言匹配，不能沿用上一集的流索引；缺语言时回退到默认 |
| C05 | 仅强制字幕开/关；关闭字幕；调文字字幕大小 | 状态符合选择；服务端烧录字幕/图片字幕可能不受文字大小影响 |
| C06 | 播放页“…”导入 UTF-8 的 SRT 或 VTT，调整时间偏移和底部位置 | 字幕文字出现并同步；退出影片或切片后清除；画中画/投屏不显示此本地覆盖字幕 |
| C07 | 使用很长的中英混排音轨/字幕名 | 菜单可滚动、可点击，不重叠 |

C02 是跨设备真实服务器验证，本地模拟测试不能代替。若发现相互覆盖，请提供**两端的操作顺序与时间点**，无需提供账号密码。

## D. 下载、连接与设置

| 编号 | 操作 | 预期 |
|---|---|---|
| D01 | 下载默认版本 MP4/MOV/M4V，暂停、继续，再进入后台 | 进度保留，继续同一后台任务；完成后经过大小和视频轨校验，可断网播放 |
| D02 | 下载中杀掉 App/重启、断网后恢复，点“重试下载” | 任务在系统保留时继续；系统移除任务时明确从头重下，不能假装已经断点续传 |
| D03 | 设置“仅 Wi-Fi 下载”，断开 Wi-Fi；再调低离线容量预算尝试下载 | 新任务等待网络或明确失败；超过预算有提示，不默默占满存储 |
| D04 | 下载无视频轨或明显损坏的文件（方便时） | 下载完成校验不通过，不出现可播放的假成功；HEVC 等“可读取但不能出画面”仍以实际离线播放验证 |
| D05 | 在来源列表长按“编辑与重新登录”，输入原账号新密码 | 不用删除来源；收藏/目录/历史保留；不同账号有明确拒绝并建议新建来源 |
| D06 | 手机通过蜂窝网络播放，关闭“允许蜂窝网络播放”再试 | 下一次播放遵循设置；远程连不上有清楚错误，不越过限制 |
| D07 | 清理海报与媒体缓存 | 重新进入后海报可重载；不删除历史、收藏或下载文件 |
| D08 | 来源地址变更或证书错误（可选） | 报错能指出来源或证书问题；不把令牌写在提示中 |

## E. iPad 与系统行为

| 编号 | 操作 | 预期 |
|---|---|---|
| E01 | iPad 横/竖屏进入媒体库、详情、收藏、下载、设置 | 可用侧边栏切换模块，详情内容不挤压或遮挡 |
| E02 | iPad 分屏/舞台管理器缩小窗口，再返回全屏 | 信息仍可操作，滚动位置和选择尽量保持 |
| E03 | 播放视频，画面出现后点“…”→“画中画” | 支持的系统/流进入画中画；返回 App 可继续。不支持时给出原因，不静默失败 |
| E04 | 用 AirPlay 选择可用设备再断开 | 声画、播放进度与路由恢复；外部本地字幕不在投屏画面中 |
| E05 | 蓝牙耳机断开、来电/其他音频打断、锁屏后返回 | 遵循系统播放/暂停状态；不会突然从头播放或丢失进度 |
| E06 | 大字体、VoiceOver 操作来源、片库、播放和设置 | 核心功能有可读标签与替代按钮，长文字不遮挡操作 |

PiP、AirPlay、分屏需要真机与对应设备；模拟器结果只能用于基础回归。
