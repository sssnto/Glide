# 1.11.0 体验步骤

1. 打开一个本地或已下载视频，点播放器上方“画面与时刻”（网格图标）。视频暂时暂停。
2. 在“内容地图”查看缩略图；点放大镜细看这一时间段，点“返回上一层”返回；点画面从标注时间播放。
3. 再打开导航，点“收藏当前时刻”，填写名称并保存。选择“时刻”页签可查看本视频版本已有的收藏。
4. 返回应用，在“我的 → 时刻收藏”查看、搜索、左滑重命名／删除；点击条目在原文件版本与位置播放。
5. 重启应用后确认收藏仍在；删除收藏不影响原视频。
6. 在提供当前版本 Trickplay 的 Jellyfin 视频中检查地图；“章节”展示文件或服务器实际提供的条目，点击后播放对应位置。
7. 导航左上角选项可清理内容地图缓存；清理后按需重新读取，不删除离线文件或收藏。

无缩略图、无章节、来源失联及版本变化均应有明确提示。动态视频链接或缺少可靠版本信息的文件源可能无法保存可恢复的时刻。本版不承诺每种来源／封装均能生成地图。
