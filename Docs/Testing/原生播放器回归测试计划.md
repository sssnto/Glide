| 缓存与倍速 | 普通播放后切换 2×，观察同一进度条的缓存层 | 缓存正常更新，倍速仍有声音；网络足够时持续播放，不能把缓冲目标当作已缓存量 |

| 控制台 | 等待自动隐藏，单击画面，再隐藏再唤出 | 一次短点即可显示；短点不跳进度，长按左右侧才快退／快进 |

| 家庭媒体浏览 | 在家庭媒体库和子目录切换「目录／视频」；目录排序后进入、返回、刷新；视频中搜索、调整范围和排序并刷本目录；重启应用 | 两种列表分开展示，视频视图不被目录占位；目录视图仅显示目录和目录排序；无子目录时可点「查看视频」；返回和刷新始终可用，切换后回到列表顶部，选择在进入子目录和重启后保留；电影／节目仍使用原有海报墙 |

| 画中画与 AirPlay | 家庭刷看与电影播放中分别打开画中画／投屏 | 系统允许时正常播放、暂停、返回；外部字幕不包含在投屏／画中画中 |

| 下载完成 | 下载 MP4／MOV／M4V，完成时进出下载页，重启应用后再播放；失败后重试 | 完整且系统可识别的文件从「校验中」进入「已完成」，不会变为中断／失败；重试提示在完成后消失，使用本地文件播放；不完整文件仍被明确拒绝 |
| 生命周期 | 播放时进后台／回来，连续开关播放器 10 次，快速切换视频 | 没有旧视频声音、过期错误或准备提示；后台策略与现有操作一致 |
| 音频会话 | 在出画面前退出并立即重新播放；连续切片；切换蓝牙／扬声器；退出后打开其他音乐应用 | 重新播放有声音，页面与控件始终可操作；退出后其他应用可恢复声音；Xcode 不再出现 `AVAudioSession Hang Risk`。iOS 27 验证系统异步接口，iOS 17–26 验证后台队列兼容路径 |

重点设备：实际使用的 iPhone 13 Pro Max，以及一台 iPad。至少覆盖局域网 Wi-Fi、远程 Wi-Fi 和蜂窝网络；真实 4K HEVC / HDR / Dolby Vision、服务器转码耗时、画中画与 AirPlay 必须在实机验证。

反馈请包含：构建版本、设备／系统、文件封装／编码、上述场景、操作步骤、实际等待时间和播放诊断。诊断不包含服务器地址、授权令牌或片名。

本地模拟服务可验证协商与恢复流程，但不代表实际服务器性能或设备硬解表现。

音频会话修复验证（2026-09-30）：Debug 模拟器与 iOS arm64 Release 未签名编译通过；iOS 26.3.1 模拟器的连续退出／重新打开、控制台自动隐藏后唤出、切片／倍速／缩放／锁定三项 UI 回归最终通过。同步音频调用只在后台串行队列执行，Debug 断言验证不在主线程。首次 UI 回归遇到卡片点击和控件遮挡问题，测试改用固定播放入口、等待返回按钮可点击、隐藏控件后缩放，再分别重跑通过。实际声音、蓝牙路由及 iOS 27 异步激活／停用路径仍需按表中「音频会话」一项实机验证。

家庭浏览切换验证（2026-09-30）：Debug 编译通过；iPhone 17 Pro／iOS 26.3.1 模拟器使用本地 Jellyfin 模拟服务，通过 `testFlattenedLibraryVideos` 回归，覆盖视图互斥、递归分页视频播放与返回、子目录进入／返回、刷新、重启保留选择和切换后保留视频搜索／范围／排序入口。手动验证无子目录提示及「查看视频」按钮。用例初次运行因弹窗后目标仍在背景、返回后目标在屏幕外、启动参数覆盖视图选择而失败；修正用例的等待目标并移除强制视图启动参数后通过。目录／视频切换本身不要求重新读取元数据。iPad 和真实服务器仍按表中「家庭媒体浏览」一项进行实机检查。

剧集切换与选集验证（2026-09-30）：Debug 模拟器编译通过，60 项核心测试通过；iPhone 17 Pro／iOS 26.3.1 模拟器的 `testEpisodeSwipeAndSelection` 和 `testSwipeZoomLockAndReturn` 两项 UI 回归通过。使用本地 Jellyfin 模拟服务覆盖两季、三集的上下滑切换、跨季选集、首末集不循环、当前集标记、重复选择当前集不重启、放大后拖动不切集、锁定后不切集，以及家庭视频原有手势。首次缩放用例的精确倍数断言未通过，改为隐藏控件后检查实际放大状态，再运行通过。队列选择及新增季／集元数据的持久化、旧记录兼容性由核心测试覆盖。真实服务器的不同语言音轨／字幕、续播同步和 iPad 布局仍按表中「剧集切换与选集」一项实机验证。
