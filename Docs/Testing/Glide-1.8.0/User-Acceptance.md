# Glide 1.8.0 体验步骤

最终独立 iPhone 包的安装状态以 [验收记录](README.md) 为准。无需 Plex 账号、飞牛或 NAS。

1. 在播放页底部点“字幕”→“字幕控制与双字幕”。
2. 在“主字幕”中导入 UTF-8 SRT／VTT，或选择同目录字幕。
3. 主字幕加载后，在“第二字幕”中选择另一份字幕。主字幕在上，第二字幕在下。
4. 分别调整两路“时间偏移”；正数晚出现，负数早出现。“偏移归零”只影响当前一路。第二字幕字号和整体底部距离在下方调整。
5. 点“完成”返回画面，暂停、拖动或切换倍速；两路使用同一播放时钟。退出后重新打开，检查两路选择及偏移恢复。
6. “关闭第二字幕”保留主字幕；“关闭全部字幕”关闭两路。已导入的副本仍可再次使用。“清除此视频的两路记忆”让下次打开重新选择／匹配。

使用自己带声音的本地视频时，也请检查兼容播放中连续暂停定位、重新播放后的声音与倍速恢复。自动检查覆盖媒体时钟和暂停状态，不等同于人工听音验收。

独立包中的“**双字幕原创验证**”本地来源包含 paired.mp4、manual.mp4 和 other 子目录。切到“目录”视图，选择顶层 paired.mp4，可使用 paired.zh-Hans.srt 与 paired.en.vtt 测试。请拖动到 1 秒以后观察；暂停在 0 秒且设置了正偏移时，字幕尚未出现是正常行为。

内嵌字幕使用单字幕模式；手动选择内嵌轨道会关闭第二字幕。双字幕首批为两份外部 SRT／VTT，外挂 ASS、双内嵌、服务器烧录组合及 PiP／AirPlay 外部字幕输出不在本版范围内。
