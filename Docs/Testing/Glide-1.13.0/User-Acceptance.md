# 1.13.0 真实片库体验步骤

独立「Glide NAS 验证」已安装最终 1.13.0（1）。原创合约的真机 25 项检查已通过；以下是用户自己的片库验证步骤，不提前记作已通过。

1. 从多任务划掉验证包，再点击图标打开正常首页。进入「搜索全部片库」；也可从片库更多菜单进入。正式 Glide 与独立验证包是两个应用，账号分别保存。
2. 搜索一部已知电影或节目。检查来源／类型筛选，同名不同作品应分开；有一致可靠 ID 的跨来源作品才集中显示。
3. 打开作品，检查来源、分辨率／HDR／编码／大小是否与服务器实际版本一致。没有返回的资料不生成猜测标签。
4. 明确选择一个版本播放，返回并重启应用再次打开，确认仍选中该入口。若所选版本已移除，应要求重选，不能自动播放另一份文件。
5. 已下载默认版本时再选择其他版本，确认播放对应文件。按来源分别保留进度，不把不同剪辑版的时间混用。
6. 搜索一个节目，加入已有或新建频道；再进入离线行程，启用连续剧模式，选择接下来 3／5 集并确认预算。频道与行程沿用默认原文件限制，非默认版本不能直接创建离线行程。
7. 来源不可用时，检查其他来源结果仍可显示，缓存资料标明状态；已下载筛选支持断网搜索、播放和定位。

本版不索引全 NAS。真实多来源、大型片库滚动、代理与网络变化下的体验结果可另补记录，不能用原创样例预先替代。
