# 官网同步 1.11.0 已发布状态

2026-10-23，用户确认 1.11.0 已发布并要求更新对外宣传网站。

## 内容变化

- 首页首屏、下载提示与版本卡片改为 1.11.0 已上架；介绍按时间选片、私人频道、内容地图与时刻收藏等完整能力。
- 清理首页、来源说明、FAQ、支持和隐私页面中将 Emby、SMB、链接及字幕功能标成开发版的旧说明。
- 更新记录将 1.11.0 列为当前商店版本，展示从 1.4.0 升级的累计变化。1.5—1.10 是并入本次发布的阶段演进记录，不暗示这些版本分别上架；1.4.0 保留为历史商店版本。
- 使用“应用界面参考”注明既有原创测试素材截图，不将它们描述成这次重新拍摄的商店成品。
- 保留地图、字幕字体、PGS、PiP／AirPlay 与来源能力边界；原有 App Store 链接、域名、样式、脚本和图片保持。

## 发布依据与验证

上架状态依据用户的直接确认。此次两次 Apple 公开查询仍返回 1.4.0，结果见 [Store-Lookup.json](Store-Lookup.json)；可能存在查询或地区传播延迟，不将其记为接口已经核实 1.11.0。网站对尚未看到商店新版的用户提供稍后刷新的说明，没有虚构发布时间、商店构建号或所有地区已同步的结论。

五个页面、123 处站内引用与语义关系通过[静态检查](Static-Checks.json)，JavaScript 语法及改动空白检查通过；对当前页面断言不再含“开发版”“开发预览”或把 1.4.0 标为当前商店版的内容。仅修改文案与现有版本卡片内容，没有改动播放代码、CSS 或 JavaScript，不重复应用核心和真机测试。

实际 Pages 提交、构建状态及全部线上文件校验见 [Deployment.json](Deployment.json)。保留先前的重设计与验收历史，没有改写旧报告。发布材料目录是本次开始前已有的未跟踪内容，未混入本次网站提交。
