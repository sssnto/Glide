# Glide 1.1.0 用户验收计划

请先用测试版验证，暂不提交商店。优先测试过去出现问题的「海贼王真人版第一集」、4K HEVC 竖屏与大码率视频。自动化结果另见同目录测试报告；本表的实机项目仍待你反馈。

## 准备

- 从现有版本升级，保留来源、常用目录、收藏、观看记录与已下载影片。
- 一台 iPhone；有条件增加 iPad。准备正常 Wi-Fi、蜂窝、弱 Wi-Fi与断网环境。
- Jellyfin 准备电影库、至少两季的节目（含特别篇）、多层家庭目录。家庭目录各层放视频，部分缺封面／添加时间；正片中准备未看、看一半、已看三种状态。
- 请记录设备、系统、App 版本、媒体名称、操作步骤；播放问题导出「播放诊断」。不要在反馈中放服务器密码或令牌。

## 必测流程

| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| U01 升级 | 打开来源、继续与收藏、常用刷看与离线 | 原资料没有清空；旧固定目录可以进入；旧记录不导致页面打不开 |
| U02 返回 | 家庭目录视频滚到第 3 页，播放／返回；目录视图滚动后进子目录再返回 | 回到先前条目附近，列表立即可见；两种视图各保存位置（快照最多 1200 条，超出可重读） |
| U03 刷新 | 在列表中间下拉刷新；刷新期间断网；恢复网络重试；筛选后重复 | 已有内容不消失／闪烁；失败有明确提示；排序／筛选变化从顶部开始 |
| U04 常用 | 设置仅当前层＋添加时间降序＋随机，点图钉；临时改成名称升序；回主页点击常用播放键 | 使用保存的规则，范围不扩展；随机收齐范围后开播，取消收集不开始播放 |
| U05 编辑 | 常用管理页长按／右滑，改名称、范围、排序和顺序，退出再启动 | 名称与规则保存；服务器目录不变；来源移除后不能误进其他库 |
| U06 节目入口 | 节目详情直接点播放；播放一半退出；个人页继续；节目详情再次继续 | 显示准确季集；节目仅一条续播卡片；直接从正确集和位置播放 |
| U07 跨季 | 看完一季最后一集；在续播页进入下一集；看完全部正片；留一集没看再检查 | 指向下一未看正片，跨季顺序正确；不自动插入特别篇；全部完成可从头看；有漏看集不显示全部完成 |
| U08 历史删除 | 收藏某集；同节目看两集；从个人页删除该节目记录 | 所有该节目本机历史卡片移除，收藏保留；不删除文件，不重置 Jellyfin 进度；家庭刷看不新增历史 |
| U09 起播 | Wi-Fi 连刷 20 段；再测蜂窝、低电量、2×、进入后台后回来 | 出画面前有预览与准备；出画面后不误报正在准备；控制不失效；不会提前启动下一视频转码；准备命中可在诊断看到 warmup_hit |
| U10 手势 | 短点、左右长按、左右倍速、上下切换、捏合拖动、锁定／解锁、控制台隐藏后短点 | 保持原交互；放大后拖动画面不切片；锁定后不能手势切片；短点不快进 |
| U11 下载队列 | 对两个支持的原文件依次确认下载；暂停首个、继续／重试；等两项完成 | 一个传输、另一个等待；暂停释放名额；继续排队；文件传输后通过校验才可播放；失败不阻塞后续 |
| U12 重启与弱网 | 下载中后台／普通退出重启、断网恢复；下载失败重试；磁盘空间不足 | 状态明确，不无限重试；完成文件不变失败；不足拒绝开始。强制划掉应用可能中断，按提示手动重试 |
| U13 真离线 | 下载完成后清空媒体缓存、断网，打开离线页播放和拖动 | 海报与标题仍在；缺图不影响播放；播放不请求远端视频；本机编码不支持的文件明确提示 |
| U14 删除来源 | 分别测试保留已下载、同时删除离线两种移除选项 | 保留时已完成影片仍能离线播放，未完成任务停止；同时删除时对应文件与清单都消失；其他来源不受影响 |
| U15 回归 | 音轨、字幕、外部字幕、旋转、AirPlay、画中画、收藏、标签／人员／相似推荐 | 现有功能可用；下一集不复用上一文件流索引；收费入口保持隐藏 |

## 性能记录

同一局域网每类视频起播至少 10 次，记录从点击到真正出画面的时间；冷启动、再次打开与下一条切换分开记录。报告 `totalFirstFrameSeconds`、恢复次数、交付方式和缓冲次数。3 秒直放／2 秒预备切换／8 秒转码是目标，不作为当前保证。转码受到 NAS 负载和网络影响，不能单看模拟器判断。

正式发布前建议完成 100 次起播与 100 次切换，并持续播放 30 分钟，观察发热、音画同步、内存与控制台。真实 HDR／杜比视界、后台系统调度需实机验证。
