# 1.7.0 手机体验

最终源码的独立「Glide NAS 验证」1.7.0（1）已安装，2026-10-20 14:28:13 完成 14 项检查：13 项真实服务／原生播放，1 项注入定位偏差的控制器契约。正式 Glide 应用未被替换。验证后电脑尝试重开正常片库被 iOS 锁屏拒绝；解锁后可手动打开该应用进行体验，无需重装。

1. 打开媒体来源 → 添加媒体源 → Emby。
2. 本次 Mac 临时测试地址：`http://192.168.0.75:8773/emby`。
3. 专用假账号：`glide-fixture`；专用假密码：`glide170-fixture`。这两个值仅用于本次原创素材服务。
4. 连接后可查看 Glide Movies、Glide Shows、Glide Home。电影含双音轨和文本字幕；剧集有两集；家庭视频含中文多层目录。电影库共 66 个条目，可测试分页与搜索。
5. 进入电影详情，先测试原文件播放，再选择音轨和字幕；播放设置可使用导入字幕、片头片尾规则。返回来源后可测试重新登录和移除。
