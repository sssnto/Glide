## 原因与行为

此前为绕开 HLS 字幕轨道起播超时，客户端单独读取文字字幕，视频流不再附带这些字幕；菜单仍只列出内核从当前流发现的轨道，因而丢失了服务器原文件的多条字幕。菜单选择也只调用内核接口，不能切换由客户端读取的服务器文字字幕。

现在播放资源保留实际媒体版本的完整字幕元数据。快捷菜单显示数量和所有服务器字幕，字幕控制中另有完整列表，按语言、格式、原始名称和轨道编号区分同语言的多个版本；内核本地轨道与服务器目录分别处理，离线文件继续使用其本地轨道。

Jellyfin 文字字幕切换独立读取所选字幕；读取成功才替换当前文字，不重新打开正在播放的视频。失败保留原字幕，连续选择取消旧请求，切片和关闭取消过期工作。关闭后可以再次选择任一文字轨；播放／暂停、进度与倍速沿用当前视频。现有 UTF-8／2 MB 限制与同源认证继续生效。

手动选择保存的是媒体版本 ID、轨道索引、格式与语言等元数据，不保存服务器字幕正文。重开播放器时验证该版本及轨道仍匹配，避免将另一版本的同号轨道当成旧选择；原有关闭／导入／内嵌字幕记忆可继续解码。离线播放不为恢复服务器字幕发起网络请求，也不覆盖已有在线选择。

图形字幕保留为显式选项，标注由服务器处理；需要服务器处理时重新协商，并保留位置与播放意图。这不替代服务器的 HDR 转换能力，不承诺之前只有 PGS 烧录的故障已被客户端文字切换修复。

## 边界

文字轨道切换在同一个视频会话内完成；图形字幕是否能成功烧录仍依赖服务器权限与转换配置，本轮真实剧集未逐一验收 PGS 烧录。菜单样例中的图形轨仅用于验证目录显示，不能计为实际解码通过。ASS 等文字格式由服务器导出 SRT 时不保留原始排版。PiP／AirPlay 字幕输出、整集长播和全格式矩阵不在本轮范围；未推送、打标签或上传商店。
