# Glide 官网重设计 · 2026-10-23

以浅色、石墨灰和系统蓝重做首页、版本动态、支持及隐私页。首页包括原创海岸播放示意、可切换的时间选片／私人频道／内容地图介绍、实际原创测试界面、来源范围、商店与开发版本、FAQ 和下载入口；手机采用单列布局，保留原生语义、键盘焦点与减少动态效果支持。

内容依据当前源码和版本验收记录；App Store 经 Apple 公开查询核实为 1.4.0，当前开发版为 1.11.0（4），两者在页面内分别标注。没有声称开发能力已经上架，没有提供不存在的测试版入口，没有使用用户私人视频或账号。
