# WebDAV 重复扫描修复 · 1.16.0（6）

## 原因与行为

重新选择来源原先总会调用 `reload()`；目录快照只在内存中，且超过 1,200 个视频不保留。应用重启、重新选择来源、修改排序，以及搜索／播放队列准备均可能重新遍历目录。

现在成功扫描的 Depth-1 目录列表按来源、根目录和账号隔离保存到本机缓存。递归恢复要求每个可达目录都有完整列表，因此空目录可以命中，缺少子目录、停止或失败的扫描不会被误当成完整索引。子目录、浏览范围、排序、搜索和队列可复用同一索引。文件大小、数量及来源数有上限，缓存可由系统清理；清理后首次进入会重新建立。

同一来源重进复用已加载结果，切换页面不再通过视图任务取消正在进行的 WebDAV 扫描。主动停止仍会取消；失败后等待用户重试，已有完整结果可保留。显式“刷新本目录”或下拉刷新重新读取目录，并更新／剔除相应子树的索引；连接重设和来源移除会清理该来源缓存。界面显示上次扫描时间，并提示手动刷新获取新增内容。
