# WebDAV 视频缩略图 · 1.16.0（9）

## 缺口与实现

此前视频卡片只读取 `video.artwork`，WebDAV 原文件通常没有服务器海报地址，因此显示影片占位图。目录封面虽然已经支持抽帧，但没有接入普通视频卡片。

现在共用的 `VideoImageCanvas` 在没有可用海报时为 WebDAV 文件生成预览，保留既有竖版画布及视频完整比例，不拉伸或裁掉竖屏视频。已有服务器海报仍优先使用；本地、Jellyfin、Emby、离线副本和网络链接原有路径保持各自的处理方式。

系统可解码的文件使用 AVAssetImageGenerator，应用视频的原始方向变换；系统无法取帧时通过兼容内核补取，MKV 等直接采用兼容路径。兼容取帧复用构建 8 的带认证分段读取通道，VLC 只接收一次性 loopback 地址，不接收用户名、密码或真实上游 URL。专用内存输出最长边 640 像素，像素内存按 32 字节对齐，静音并关闭字幕，不创建可见播放器、不参与主播放音频会话。解码、停止和资源释放在后台完成。

## 滚动与缓存

- 列表卡片按需加载，首次任务等待 200 毫秒以略过快速滑走的项目。全局最多两个取帧任务，同文件的请求串行复用结果，取消后尚未启动的排队任务不会获得解码槽位。
- 对可见项目取消，系统生成器取消请求并关闭认证加载；兼容生成器取消输入并在后台等待解码器停止后释放槽位，避免遗留不可见播放器。
- 缩略图保存为小 JPEG，来源、账号、文件地址和修改时间参与缓存标识，磁盘文件名使用现有 MediaCache 哈希；复用时间七天，内存及磁盘容量沿用现有上限。图片解码和 JPEG 编码不在主线程执行。
- 未能取帧的文件暂留占位图，失败结果短暂缓存，手动刷新可重试。视频新增独立 `fileModifiedAt` 字段，旧片库数据仍可读取。播放器保存方向或手动刷新时更新视图请求版本，缓存代次检查阻止旧取帧任务回写过期预览。
- 取帧通过流式／Range 读取，不要求先下载完整原片；实际读取量取决于容器索引和服务器，不承诺固定流量或每种损坏文件都能生成画面。
