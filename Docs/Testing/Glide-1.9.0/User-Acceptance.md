# Glide 1.9.0 体验步骤

无需 Plex 账号或 NAS。2026-10-21 已将独立「Glide NAS 验证」1.9.0（1）安装至 iPhone，并在两轮自动验证通过后打开正常片库；详细结果见 [验收记录](README.md)。

1. 打开本地来源“双字幕原创验证”，选择顶层 paired.mp4。字幕菜单选择 paired.zh-Hans.srt；也可以播放自己的视频并导入对应 SRT／VTT。
2. 播放页底部“字幕 → 字幕控制与双字幕 → 字幕全文与台词定位”，点击任意一句跳转，或搜索台词。当前句高亮；滚动后停止跟随，可主动重新开启。
3. 点台词旁的重播按钮，从该句开头播放到结尾后暂停。字幕控制中的“单句重播与 A–B 循环”也可重播当前句；未加载外部主字幕时不提供全文提取。
4. 在循环面板设起点 A，继续播放或快进至终点，设 B 开始循环。两点至少相隔 0.5 秒。面板底部固定“退出”入口，播放画面控制栏也有退出按钮。
5. 暂停时循环暂停，改倍速后按新倍速循环；手动定位到区间外或切换视频时退出。循环期间片尾跳过与自动下一条暂挂，退出后恢复。
6. 在“字幕样式与预览”分别调整两路字号、颜色和描边，设置背景透明度并观察预览。保存立即生效，重新打开仍保留；可恢复默认样式。

请用带声音的自有视频人工检查循环和单句播放的听感、定位后音量与倍速，以及横屏、长台词和大字体的可读性。本地原创样例与时钟检查不能代替所有实际编码、HDR／4K、NAS 和外部输出场景的验收。
