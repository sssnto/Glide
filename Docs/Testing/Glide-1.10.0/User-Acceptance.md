# 1.10.0 体验步骤

## 私人频道

1. 打开“首页 → 新建频道”，填写名称，进入“选择内容范围”。可选择演示视频、已连接来源的媒体库、剧集、目录或单片；点加号选中，任意层级均可点“完成”。
2. 检查所选范围和规则。默认避开最近七天开播的内容，可关闭；未看完的剧集保留续播顺序。按需开启“只播未看完的内容”。保存频道。
3. 在频道页查看本次编排，点“开始播放”。确认实际画面、自动下一条、前后切换、暂停及“返回频道”。剧集与目录交替编排，每部剧内部保持季集顺序。
4. 返回后已实际开播的普通视频应从最近去重结果排除；仅浏览预览不改变开播记录。在频道菜单中可编辑规则、重新准备或清除开播去重记录。重启应用后频道仍存在。

## 给我选一部

1. 从首页进入，选择 20／45／90 分钟或自定义 5–240 分钟，选择内容类型。
2. 在“内容范围”中选择一个明确的媒体库或目录。检查候选的来源、片长／剩余时长和推荐理由。未看完影片按剩余片长参与筛选，不截断长片；同一部剧只推荐当前顺序中下一可看的集。
3. 选中候选后应显示实际画面，暂停、拖动和既有播放设置可用；点“返回选片”回到原范围。“换一组”在候选不足时会明确说明重新展示。
4. NAS 文件没有可靠片长时，会显示未参与推荐的数量，仍可加入频道。媒体服务器可使用其片长元数据；本地文件每次最多按需读取 200 条片长。

范围准备超过限制、账号改变、来源移除或网络失败时应有明确提示，可修改范围或重试；离开页面应取消准备。不会把失败或部分读取当作完整候选。频道只保存规则、内容身份与开播记录，不复制／删除原视频，不保存临时播放地址或凭据。
