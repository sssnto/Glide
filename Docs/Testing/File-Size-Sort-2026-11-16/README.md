# 文件大小排序验收

日期：2026-11-16。

- 11 项 XCTest、295 项 Swift Testing 通过；新增 6 项覆盖大文件整数精度、稳定顺序与未知大小、分页查询、旧记录、WebDAV 有效 propstat、默认电影版本及旧目录缓存迁移。
- 本机官方 Jellyfin 12.2 容器准备 205 个原创 MP4，使用 `free` box 填充产生不同的真实字节长度。逐个核对服务器默认媒体版本 `Size` 与本地文件字节数相等。
- iPhone 17 / iOS 26.3 完整界面用例通过。原生登录和媒体库入口先验证，再通过排序菜单选择大小降序，确认原本在第二页的 `size204` 排到首位、已加载 205 条；切换升序后 `size000` 排到首位，大小信息不是未知。
- 主应用 iPhoneOS Release 构建通过。
- 原创测试容器已停止。未操作用户 NAS 或私人视频，排序无需升级服务端插件。
