## P. 购买与权益

| 编号 | 操作 | 预期 |
|---|---|---|
| P01 | 首次进入“设置 → Glide Pro” | 免费功能与 Pro 权益明确；价格来自 App Store；商品不可用时不出现假价格或付费按钮 |
| P02 | 沙盒完成一次购买 | 只按一次购买；Apple 验证通过后立即显示已拥有；新建离线下载和个性化设置可用 |
| P03 | 取消支付 | 无权益、无“购买成功”提示；基础播放与既有离线文件仍可使用 |
| P04 | 用 Ask to Buy 模拟待批准，随后批准或拒绝 | 等待期不解锁；批准后自动解锁，拒绝后可重试 |
| P05 | 重启 App、断网重启、重装后恢复购买 | 已验证权益尽可能持续；恢复购买可找回；不依赖 UserDefaults 的自定义已购布尔值 |
| P06 | 同 Apple 账号另一台设备点击恢复 | 出现相同权益；不要求重复付费 |
| P07 | 沙盒退款或撤销交易 | 收到状态变化后新建 Pro 操作被锁定；现有离线文件仍可查看与删除，免费播放不受影响 |
| P08 | App Store 商品不可用、网络断开、验证失败 | 显示清楚的可重试状态；不伪造权益、不崩溃 |
| P09 | 不同地区 App Store 账号打开购买页 | 显示该地区 StoreKit 返回的价格和币种，不写死人民币 |

## R. 隐私、支持与发布

| 编号 | 操作 | 预期 |
|---|---|---|
| R01 | 设置打开“数据、隐私与帮助” | 存储、Jellyfin 同步、诊断和购买说明可读；支持邮箱可打开邮件 |
| R02 | 手机和电脑打开公开隐私、支持页面 | HTTPS 有效、移动端可读、无 404；App Store Connect 中的 URL 指向同一版本 |
| R03 | 发送脱敏诊断前预览 | 不含密码、令牌、片名或完整服务器 URL；发送动作由用户主动触发 |
| R04 | 清缓存、删记录、移除来源和离线文件 | 每种动作范围清楚；不误删服务器媒体；相关本机密钥和缓存按说明处理 |
| R05 | 按发布清单从全新安装连接到播放 | 新用户不需要开发者解释；审核演示账号和素材有授权且可访问 |
| R06 | TestFlight 小规模外部测试 | 记录邀请数、安装数、可成功连接/播放的分母及问题；不收集私人片名和地址 |
