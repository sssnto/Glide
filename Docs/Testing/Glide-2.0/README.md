# Glide 2.0.0（1）界面与交互验收

日期：2026-11-11。基线：1.16.0（13）及用户已完成的 NAS Toolkit 1.1.0 测试。

## 环境与范围

- Xcode 27.1；使用 iPhone 17／iOS 26.3.1 模拟器，编译 SDK 为 iOS Simulator 27.1。
- 独立包 `com.songpeng.glide.v2preview`，显示名“Glide 2 预览”；没有覆盖手机主应用。
- 原创内置视频和仅监听 `127.0.0.1:8768` 的合成媒体服务；没有访问生产账号、私有 NAS 或修改远程媒体。
- 任务页的服务器用例仅返回合成状态。原位多选只勾选、取消，不提交保存。

## 界面路径

最终结果和截图见本目录的 Validation.json、UI-Summary.json 与 Screenshots。用例检查：

| 路径 | 检查点 |
|---|---|
| 主导航与播放 | 四个有文字的页签，无 More；观看历史关闭后进入单视频播放器；返回观看；内置演示片库首排媒体上沿低于 300 pt（不外推为所有远程目录的实测值）；收藏、离线和设置可达；实际首帧显示 |
| 明暗与大字号 | 跟随系统／深色实际画面；最大辅助字号下文件卡片使用单列左图右文，整行宽度足够 |
| 电影与原位勾选 | 真实目录和详情页面；选择在当前海报网格发生；勾选有可访问性值；取消恢复浏览；播放主按钮可触达 |
| 任务 | 合成运行中批次的已保存／待处理／总数；需处理筛选；任务详情；保留待核对时的重试限制 |
| 设置与诊断 | 从观看页设置入口进入；滚动找到声音、下载和诊断；分享诊断入口可达 |

首轮 2 项界面用例通过后，按截图进一步调整了收藏内容顺序、大字号卡片与历史弹层交接。第二轮的 3 条主路径通过，另有两处测试定位仍使用旧首屏／目录假设，已修正。复核还捕捉到一次设置按钮未弹出，已将弹层状态从工具栏组件上移至页面，并等待可见状态后再继续测试。中间两轮受到模拟器会话与诊断收集停滞影响，临时产物也被清理；最终使用项目缓存下的独立构建重新验收。中间轮次不能视作全量通过。

## 性能与后续验收

本次结构性改动保留懒加载、稳定 ID、分页、预览缓存、解码尺寸分桶和限流；任务轮询随页面与前台状态取消，汇总不触发旋转写入。未采集 Instruments，不声称实测帧率或内存改善数值。

正式发布前需补：主应用升级路径、用户真实 Jellyfin／Emby／WebDAV／SMB 片库、实体机触控及长列表滚动，Duo 展开／折叠与分界连续性。音轨、完整 ASS／PGS、无画面回退、方向保存与还原沿用现有实现，本轮没有把模拟器 UI 冒充这些真实媒体验收。
