# Glide 1.0.1（9）真机测试：VLC 刷看

> 历史测试计划。2026-09-30 起播放器已统一为原生 AVPlayer，当前验收请使用 [原生播放器回归测试计划](原生播放器回归测试计划.md)。

在“设置 → 版本”确认是 1.0.1（9）后，用家庭视频目录和电影/节目各选几部熟悉的片源测试。反馈时附上视频信息、播放诊断以及大致网络环境即可，不必发送账号、完整服务器地址或原片。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 起播与兼容 | 播放 MP4、HEVC、MKV 等家庭视频，分别在局域网和外网尝试 | 尽快出画；不支持的流自动切换兼容播放，不停在黑屏或要求手选画质 |
| 进度条 | 播放和暂停时分别拖到中间与已缓冲区域，再向前后拖动 | 手指能拖动滑块；松手后画面定位到目标附近，暂停意图保持不变 |
| 视频信息 | 播放界面右上角“··· → 视频信息” | 显示当前内核、传输方式、视频编码与尺寸；服务器提供时显示封装、音轨、字幕 |
| 刷看手势 | 短点画面、轻点时手指略微移动、连续左右滑动后短点；上滑、下滑、右滑、左滑；分别长按画面左、右侧 | 短点和轻微移动均能显示或隐藏控制台，不跳转进度；连续滑动后仍可短点呼出控制台；滑动切片和切 2×/1×；长按左/右侧快退/快进设置的秒数，不改变系统亮度或音量 |
| 自动隐藏与锁定 | 进入播放器后不操作，等控制台自动隐藏，再轻点画面；点开锁图标锁定、再解锁 | 第一次轻点即可呼出控制台；未锁定显示开锁图标，锁定后显示闭锁图标；解锁后播放手势恢复 |
| 播放记录 | 刷看数条家庭视频并拖动进度，回到“继续与收藏” | 不出现新观看记录；手动收藏仍会保留 |
| 电影/节目 | 从详情页播放并退出重进 | 续播进度仍有效；节目仍按季集浏览 |
| 弱网恢复 | 在较慢网络下播放高码率视频或播放期间切换 Wi-Fi/蜂窝网络 | 可自动恢复或给出清楚错误；诊断可反映内核与恢复次数 |

如出现黑屏、无声、卡顿或拖动失败，请记录片源编码、封装、分辨率、是否使用 VLC、诊断里的 `events`/`totalFirstFrameSeconds`，以及实际等待时间。不要将含授权令牌的媒体 URL 发出。
