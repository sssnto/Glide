# Glide 1.15.0 体验检查

本次按用户选择使用官方 iPhone Duo 模拟器验收；未进行 Duo 实体机验收。

## 推荐内容

1. 首页打开“给我选一部”，选择包含电影与剧集的内容范围。
2. 剧集应先看到剧名，再看到季、集编号和单集标题；电影显示片名。年份与类型按服务端实际提供的信息展示。
3. 片长或剩余时长、推荐理由继续显示；连接来源使用“来源 · 名称”，不再把短来源名误当作品信息。
4. 点击推荐仍打开对应视频，并在有进度时续播。缺失剧名时明确显示“剧名未提供”；缺失年份或类型不补造。

## Duo 交互

1. 在外屏、展开、书本与桌面姿态浏览片库和目录；检查网格、侧栏、媒体详情及摄像头避让。
2. 搜索框输入文字后切换姿态，确认文字与结果仍保留。
3. 播放视频，选择倍速和音轨；暂停后反复合拢、展开与旋转，确认仍暂停且选择保留。连续播放只在自然结束时切换下一条。
4. 在播放设置创建片段，输入名称，保持键盘打开后切换姿态，确认草稿和输入仍保留。
5. 使用大字体和 VoiceOver，检查信息顺序、播放操作与清除搜索按钮。

自动化与截图均使用原创素材、独立 QA 状态，不读取私人媒体或已保存服务账号。完整证据和已知日志警告见 [验收记录](README.md)。
