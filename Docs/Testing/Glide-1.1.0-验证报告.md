## 回归中发现并处理

- `PlaybackMode` 新增 Codable，确保常用规则可兼容解码。
- 不独立截断分页内容与服务器游标，避免快照恢复跳过条目。
- 有漏看集时不宣称节目全部完成；明确本机重置进度优先。
- 下载确认的 SwiftUI 可访问性有嵌套同名节点，测试用唯一匹配；来源较多时添加入口移到固定工具栏，列表定位当前来源。
- 家庭预览与个人海报接入认证图片缓存；保留长宽比。首帧预览位于视频渲染层上方，避免被黑色原生视图遮住。
- 标为已看同步本机完成进度；关闭字幕偏好参与起播选择。
- iOS 27 控制台隐藏后，系统可访问性树仍可能保留非可点击节点；隐藏判断改为不存在或不可点击，唤起后要求节点存在且可点击。修改后的回归通过。

## 环境中断与限制

首轮界面运行的下载确认因测试节点歧义失败，固定目录测试受启动时已有影视页面影响；测试脚本已调整。后续下载测试在旧模拟器键盘的动画完成等待中多次停留 60 秒，随后中断；新模拟器冷启动也超时，CoreSimulator 服务已重启。重启期间一次资源准备测试的 Runner 因模拟器 Shutdown 终止，属于环境中断，不能计作测试通过。

下载队列的双任务传输／暂停、移除来源时同时删除完成文件、列表长距离滚动恢复、Wi-Fi 准备命中与取消仍需完成界面／实机验收。核心队列决策通过不等于后台 URLSession 全流程通过。
