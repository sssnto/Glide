## 用户流程与实现

首页或「我的 → 精彩片段集」进入。播放设置收藏精彩片段，输入名称，滑动起点与终点，使用 ±1 秒微调，预览后保存到现有或新建合集；旧时刻可通过左滑或长按补充终点保存为片段，不改写原时刻。至少 0.5 秒且必须处于视频时长内，非有限／越界输入不能保存。

支持按片段、视频或合集名称搜索；合集可重命名、选择片段作为封面、长按上移／下移、编辑拖动重排、添加已有片段或移出条目。删除合集保留片段；从全部片段删除同时移除各合集中的引用、失效封面与游标，始终保留原视频。最多 1000 个片段、100 个合集、每个合集 100 段。独立可恢复快照，数据读取失败不静默重置。

播放使用现有生产 PlaybackController 与两种内核。明确区间起止，进度条显示片段自身时长，定位被夹取到区间；屏蔽片头片尾自动跳过、A–B 循环和剧集全队列扩展。同视频多段各有稳定 ID，不以视频 ID 去重；末尾切换下一段，跨文件有正常加载间隔，整轮播完显示结束状态。系统内核使用 AVPlayerItem 终点，VLC 使用输入层 stop-time 与控制层守卫，保留各自实测误差，不承诺逐帧剪辑或无缝切换。

合集游标独立保存，不写正片本机续播或媒体服务器观看状态；进入完整视频后使用既有正常观看语义，返回片段时恢复合集的区间位置。完整视频与片段在同一展示层切换，避免嵌套完整播放器；预览使用专用控件身份，避免界面自动化误点同名背景按钮。

文件引用沿用来源、账号、媒体版本与本地大小／修改时间校验，新增来源地址绑定；旧时刻没有该字段时保持兼容。播放前核验，失效时要求用户确认，不改播其他版本。在线来源片段不因后来下载同名文件而静默更换播放文件；从离线入口创建的片段只读对应本机副本，不依赖原服务器仍存在。

本机可解码视频按需生成预览，最多并发 2 张、内存缓存 16 MB；远程条目沿用服务器封面，不为封面启动转码会话。缩略图或播放均不复制、剪切或导出源视频。

## 过程与边界

首轮实测发现 VLC 倍速时终点超出约 0.65 秒，增加输入层 stop-time 后通过。另一轮测试暴露先前验证改变了默认内核，补齐每轮内核初始化、断言与恢复，避免把 VLC 结果标成系统结果。失败记录见 [首轮](Simulator-Contract-First.json)、[第二轮](Simulator-Contract-Second.json)。

界面走查修正竖版预览图挤压区间控件、键盘收起、完整视频与片段嵌套层级。短区间可能在自动化观察前已结束，因此创建预览用例先暂停并确认真实画面，再点击片段专用播放按钮验证到点停止；未删除或跳过断言。首次 UI、后续复测与中间失败均保留在 Logs，最终以 UI-Verified.log 为准。

本轮只使用原创动态视频及独立 QA 目录，无需私人媒体服务器账号。独立包没有替换正式 Glide。本轮真机报告是实际播放证据，不等同于用户已经执行飞行模式；未记录 HTTP 请求计数，不能宣称测得全链路零请求。离线专项检查原来源不存在时生产离线解析与本机文件出画面。Jellyfin／Emby／SMB／WebDAV、远程转码与编码完整矩阵仍需实际用户媒体验证，不能据本机原创样例宣称全部通过。无新增全片分析、AI 剪辑或片段导出。
