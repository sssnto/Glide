# 1.14.0 体验步骤

独立包与正式 Glide 并存。首页或「我的 → 精彩片段集」进入管理；正式应用未被独立包替换。测试自产原创视频，无需新账号或 NAS。

1. 播放视频，打开右上角播放设置，点「收藏精彩片段」。填写名称，滑动设置起点／终点，使用 ±1 秒微调。预览应从选定起点开始，到终点停止；至少 0.5 秒。
2. 保存到现有或新建合集，回到精彩片段集检索名称。退出并重开，条目应仍可用。
3. 打开合集播放，快进和拖动不能移出片段范围，进度条显示当前片段自身时长。终点自动进入下一段；同一视频的多个区间各自保留。上下滑或显式上一段／下一段切换。
4. 在第二段退出，再次打开合集点「接着刷」应恢复第二段及区间内位置。整轮结束后显示已刷完，可重新开始。
5. 点「观看完整视频」，应从当前位置播放原版本，显示完整时间轴。点「返回精彩片段」，应回到合集当前片段；片段回看本身不覆盖正片续播或服务器观看状态。
6. 长按合集里的片段，选择封面、上移／下移或移出；编辑模式也可拖动重排。重命名与删除合集后，片段和原文件仍保留；从全部片段删除只删除该片段引用。
7. 从「我的 → 时刻收藏」左滑或长按条目，选择「保存为片段」，补充终点。原时刻收藏保持可用。
8. 在已有离线视频内创建片段，关闭 Wi-Fi 和蜂窝网络后重开应用，检查播放、切段和续刷。服务器片段不会自动改绑另一个下载版本。文件被删除、替换或来源账号／地址改变后，应提示问题，不播放其他文件。

原创合约／实际解码与私人服务器体验分别记录。真机报告并不代表已完成全部 Jellyfin、Emby、SMB、WebDAV 与编码组合，也不代表用户已执行飞行模式。系统与兼容内核分别测量边界误差，跨文件切换不承诺无缝。
