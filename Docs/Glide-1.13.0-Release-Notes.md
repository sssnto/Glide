# Glide 1.13.0：统一片库

开发构建 1，发布说明草稿；尚未提交商店。

## 此版本的新增内容

- 新增统一片库搜索，一次查找 Jellyfin、Emby、本地视频及已下载内容，支持内容类型和来源筛选。
- 同一作品的不同来源和媒体版本集中展示，来源、格式与大小更清楚；缺少可靠标识的同名内容分别保留。
- 支持选择播放版本并记住上次选择，播放前重新核验版本，避免已有下载副本覆盖本次所选文件。
- 搜索结果可以直接加入私人频道，或带入离线行程确认页，减少重复寻找。
- 已下载内容支持断网搜索和播放；慢来源独立返回，其他来源的结果可先浏览。
- 沿用苹果原生搜索、列表和导航，保留现有目录浏览及播放操作。

## 范围说明

远程搜索首先支持已连接的 Jellyfin／Emby，本地扫描限已授权目录，离线结果限本机已完成下载。自动聚合依赖同类型且一致的 TMDB／TVDB／IMDb 标识；不依据相似片名猜测合并，也不自动跨剪辑版本同步进度。

搜索缓存可能保留来源上已经变化的显示资料，进入作品时刷新版本并在播放前再次校验；缓存不代表服务器在线。频道沿用所选来源默认版本，离线行程仍只准备支持下载的默认原文件；具体内容与容量需用户确认。

本版不包含全 NAS 索引、自动影视刮削、新增 Plex／飞牛或跨设备同步。实际范围见 [产品规格](Glide-1.13.0-Product-Plan-2026-10-26.md)，验证结果见 [验收记录](Testing/Glide-1.13.0/README.md)。
