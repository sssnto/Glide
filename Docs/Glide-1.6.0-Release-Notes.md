# Glide 1.6.0 发布说明（开发验收完成）

本地构建 1.6.0（1），本轮开发验收通过，未提交商店。

## 此版本的新增内容

- 新增链接播放：保存 HTTP(S) 视频地址，再次打开继续观看；支持编辑过期链接与可选请求头。
- 新增 STRM 导入：从 UTF-8 STRM 文件读取视频地址，保存到链接列表。
- 新增片头片尾规则：按视频设置时间，Jellyfin 剧集可按节目共用；支持点击跳过或主动开启自动跳过。
- 接入 Jellyfin 片段标记，在对应时段显示片头、片尾、前情、预告及广告的跳过入口。
- 链接地址与请求头存储在设备钥匙串中，普通片库快照仅保留名称和标识。

链接播放使用系统播放器；带自定义请求头的 HLS 暂不支持。每个 STRM 仅含一条绝对 HTTP(S) 地址，本版不扫描 NAS 内的 STRM 或播放列表。Jellyfin 跳过依赖服务器已生成的标记，不包含客户端自动识别。

实际验收见 [1.6.0 记录](Testing/Glide-1.6.0/README.md)。
