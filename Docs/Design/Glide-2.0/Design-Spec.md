# Glide 2.0 · 观看优先的媒体工作台

日期：2026-11-11。基线：1.16.0（13）与 Toolkit 1.1.0。目标：重做信息架构、内容密度和操作路径，复用已验证的播放与文件处理能力。

## 设计依据

用户已反复指出：媒体身份不清、标题和留白过大、功能分散、手势和切换卡顿，以及批量操作脱离原列表。用户明确偏好 Apple 原生交互。以下方案基于实际反馈与 Apple 规范推导，尚无独立用户访谈或可声称的偏好统计。

Apple 依据：[Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)、[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)。少而稳定的主导航、将内容操作放在工具栏、优先系统控件、44 pt 常用触控目标、动态字体和克制使用玻璃，是本版的约束。

## 能力与新归属

| 用户想做的事 | 已有能力 | 2.0 入口 |
|---|---|---|
| 接着上次看 | 观看进度、剧集续播、下一集、来源版本 | 观看 → 继续观看，片名先于单集名 |
| 找现在能看完的 | 按时长挑选、私有频道、去重与剧集顺序 | 观看 → 给我选一部／我的频道 |
| 找自己的片 | Jellyfin、Emby、SMB、WebDAV、本地、链接／STRM、统一搜索 | 片库；全局搜索直接可达 |
| 看片与调节 | 系统／兼容内核、原画、ASS／PGS、音轨、字幕、倍速、导航、缩放、横竖屏 | 播放器，常用项不藏进多级设置 |
| 留住内容 | 视频收藏、时刻、片段、合集与串播 | 收藏；观看历史作为二级切换 |
| 离开网络继续看 | 下载队列、离线文件、随身行程、离线核验 | 任务 → 离线片库／随身行程 |
| 修正和整理 | 原位多选、方向修正、服务器串行队列、备份还原、预览修订 | 原片库勾选；进度到任务 |
| 管理连接和偏好 | 媒体来源、存储、播放和字幕偏好 | 来源按钮／工具菜单中的设置 |

## 信息架构

手机固定四个主入口：**观看、片库、收藏、任务**，避免系统自动出现 More。展开设备和 iPad 保持同一结构并适配侧栏。旧离线页签迁移到任务，旧设置／来源页签回到片库，功能保留在管理入口。页签切换保留导航状态。

### 观看

首项为继续观看，先认出作品和下一步；有进度才显示进度条。随后是“给我选一部”“我的频道”，最后提供当前片库和来源。空状态直接提供连接、浏览和真实原创演示，不展示虚构推荐或观看历史。设置和搜索在导航栏，不占据首屏列表项。

### 片库

导航标题只出现当前目录名；连接名和路径用一行轻量导航。移除重复大标题、计数、提示和独立播放模式面板。媒体／目录保留原生切换，搜索和工具集中处理。网格上方只保留小号计数及排序、筛选、播放命令。

家庭视频和目录仍用竖版预览槽，画面完整适配。电影用海报；单集显示作品名和季集，不能只剩“第 1 集”。批量选择就在原网格，勾选不打开播放器，不重新列举整库，“全选已加载”语义明确。

首屏目标：390 × 844 pt 常规字体下，已加载目录的第一排缩略图顶部不超过约 300 pt；这是验收目标，尚不是已测结果。

### 收藏

默认显示收藏视频，观看历史作为同页切换。时刻和精彩片段保留独立入口。每行展示作品身份、来源与状态，移除操作只影响记录或收藏，不误示为删除服务器原片。

### 任务

统一看到下载和服务器旋转，提供全部、进行中、需处理筛选。每条任务展示标题、来源、阶段、进度和错误；保留两种任务各自真实的暂停／继续语义，不假装是同一个后端队列。离线片库和行程在本页一键进入。读取汇总不创建旋转或上传。

### 详情与播放器

详情采用紧凑海报＋身份＋资料，播放主动作清楚，技术参数和简介分层。播放器顶栏优先作品名，季集和片名为第二行；单文件隐藏无意义的上一部／下一部占位。字幕、音轨、倍速快捷入口保留。原样 ASS、PGS、缩放、内核和文件发布逻辑不在本次视觉重构中重写。

## 视觉系统

- 系统语义前景、灰阶背景、系统蓝强调操作；错误配合文字，不只用颜色。
- 默认跟随系统明暗，播放器深色。媒体承担色彩，玻璃用于导航和浮动控件。
- 系统字体，页标题行内；段标题约 17–20 pt，媒体标题 subheadline，说明 caption／footnote。大字号减少列数，文件卡片改为左图右文，避免整屏只有一张高海报。
- 16 pt 页面边距，8／12／16／24 pt 间距节奏，卡片圆角约 10–14 pt。
- 常用命令至少 44 × 44 pt；选择状态有形状和可访问性值。
- 只动画化用户触发的局部变化；尊重减少动态效果。轮询和图片加载不做整页转场。

## 性能与兼容性

沿用稳定 ID、目录缓存、分页、尺寸分桶、图片降采样及预览限流。任务汇总受页面生命周期和前台状态约束，相同批次去重。播放时钟继续由时间轴等子视图消费，后续用 Instruments 验证实际更新范围。旧系统采用原生常规材质，不用整层自制模糊。

不更改账号、收藏、续播、离线文件和服务器备份的数据格式，页签迁移有显式规则。Toolkit 1.1.0 保持兼容，客户端大版本不要求更新 NAS 插件。

## 版本与验收

2.0.0（1）作为首个候选，先用独立预览包和原创素材验收，不覆盖稳定的 1.16.0。所有内容和任务入口调用真实能力；缺少来源时明确空状态。

必须验证：四页签无 More、旧页签迁移、片库首屏内容位置、目录返回与滚动、原位多选、统一搜索、收藏与历史、离线与旋转任务入口、单文件播放、常用音轨字幕入口、明暗和动态字体。性能结论区分结构性改进与 Instruments 实测，不编造帧率、内存或满意度。
