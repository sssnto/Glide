# Glide 2.0.0（1）候选 · 界面与交互重构

## 使用变化

- 底部导航固定为“观看、片库、收藏、任务”。设置从观看、收藏、任务页右上角进入，片库的更多菜单也可进入。来源仍可从片库左上角切换。
- 观看页先展示继续观看，提供按时间选片、私人频道、当前片库和来源。无观看记录时，提供真实原创演示与连接入口。
- 文件片库去掉重复的大标题、扫描时间和独立播放模式面板；范围、排序、收藏筛选与播放顺序统一收进筛选菜单。下拉刷新继续可用。
- 剧集卡片和播放器优先展示剧名，补充季集信息；单文件播放收起无意义的前后项控制。
- 收藏默认展示已收藏视频，可切换观看历史。精彩片段、时刻和离线片库继续保留。
- 任务页汇总离线下载与多个 Jellyfin 连接的旋转队列，按进行中、需处理、全部筛选。点击进入现有任务详情执行暂停、继续或核对。
- 批量旋转仍在原视频网格直接勾选。NAS Toolkit 1.1.0 无需更新。

## 升级数据

沿用原有媒体来源、进度、收藏、离线和备份格式。旧“离线”页签恢复到“任务”；旧“设置”“媒体来源”页签恢复到“片库”，通过管理入口继续访问。

## 本轮验证边界

使用独立 `com.songpeng.glide.v2preview` 包、原创素材与模拟器走查。该包不复制生产账号，不运行 NAS 写入测试。本次改动集中在导航与展示，播放内核、字幕渲染、文件旋转和服务器发布机制沿用现有实现。

正式发布前仍需主应用升级、真实片库和实体机交互回归；不能用模拟器截图替代这些验收。
