# Glide 1.12.0：离线随身片库

开发构建 1，发布说明草稿；尚未提交商店。

## 此版本的新增内容

- 新增随身片库：按观看时间和容量生成行程候选，确认后统一准备，出行前把想看的内容带上。
- 连续剧支持打包接下来 3 集或 5 集，按季集顺序选择，并跳过明确已看完的内容。
- 支持本地视频、Jellyfin 与 Emby 原文件加入行程包，新增 MKV 离线兼容播放。
- 保存可获取的封面、简介、章节及已选配套字幕；ASS 保留原脚本和可获取的字体，缺失资料明确提示。
- 新增出发前离线检查，静音试播本机文件，区分“已下载”与“已确认出画面”。文件或配套资料变化后提示重新检查。
- 支持断网后的连续播放、切换与本机续播，重启应用后仍能打开已下载内容。
- 行程包共用已有下载；清理时可只移除行程包，或清理未被其他行程包引用的本机副本。

## 范围

支持 MP4／MOV／M4V／MKV 默认原文件版本，实际编码需本机解码器支持；检查通过不代表整部影片所有位置都已解码。远程下载依赖来源的原文件访问权限。仅保存可读取的已选配套字幕与字体，不承诺下载全部服务器字幕或补齐未提供的原字体。

本版不含 SMB／WebDAV 下载、自动补集或跨设备同步；NAS 在线播放仍保留。后台下载受 iOS 调度限制，失效任务可重新下载，不承诺任意字节断点续传。详见[范围](Glide-1.12.0-Product-Plan-2026-10-23.md)与[验收记录](Testing/Glide-1.12.0/README.md)。
