# Glide 1.15.0 发布说明

目标版本 **1.15.0（3）**。2026-11-07 已核对正式归档；Apple 美区公开版本为 1.11.0，所以下列文案覆盖 1.12—1.15 累计更新。本次没有执行上传或提交，后台状态以 App Store Connect 为准。

## 此版本的新增内容

这次更新，让自己的片库更好找、更好带走，也更值得重看。

- 统一片库搜索：一次查找 Jellyfin、Emby、本地视频与已下载内容，按来源和类型筛选。同一作品的不同来源与版本集中展示，选择后记住上次使用的版本。
- 离线随身片库：按可用时间与容量准备行程包，连续剧可选择接下来 3 集或 5 集。支持保存可获取的封面、简介、章节和已选配套字幕。
- 出发前离线检查：静音试播本机文件，确认出画面与配套资料；已准备内容可在断网后连续播放、切换与本机续播。
- 精彩片段集：为喜欢的画面设置起点、终点，预览并收藏；将不同视频的片段组成合集，排序、选择封面，退出后继续回看。
- 推荐内容更清楚：剧集显示剧名、季集编号和单集标题，电影补充年份与类型，片长、来源和推荐理由一目了然。
- 双指缩放更顺畅：减少系统与兼容内核缩放时的重复布局，改善部分视频放大、缩小和拖动时的卡顿，保持 ASS 字幕与画面同步缩放。
- 适配 iPhone Duo：片库、目录、详情与播放控制随内外屏空间调整，支持展开与半折叠分区；优化切换姿态时的播放、暂停、音轨和编辑草稿连续性。
- 改善搜索输入、大字体排版、摄像头区域避让和 VoiceOver 播放操作。

远程片库需要自行提供可访问的服务器。行程包支持本地及 Jellyfin／Emby 默认原文件的适用类型，实际编码需设备支持；片段集保存时间范围与原视频引用，不导出新视频。
