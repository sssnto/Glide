# Glide 官网与发布

域名：[glide.sssnto.cn](https://glide.sssnto.cn/)。网站源码以本仓库 `Website/` 为准。

实际 GitHub Pages 仓库是 [sssnto/glide-privacy](https://github.com/sssnto/glide-privacy)，不是应用源码仓库。当前使用其 `main` 分支根目录发布，保留既有 CNAME 和域名分发配置。只推送 Glide 仓库不会自动更新官网。

## 更新网站

1. 修改 `Website/` 中的静态页面与资源，无需前端依赖或构建。保持首页、更新记录、支持与隐私说明的版本一致。
2. 运行 `python3 Scripts/check_website.py`、`node --check Website/site.js`。用本地 HTTP 服务检查桌面、手机布局、功能标签切换、键盘操作与 FAQ。
3. 克隆或更新独立 Pages 仓库，保持工作区干净。运行 `python3 Scripts/sync_website.py --checkout /绝对路径/glide-privacy`。脚本核对远端、CNAME 和本地状态，只复制公开网站文件，不提交或推送。
4. 审阅 Pages 仓库 diff，提交并推送 `main`。检查 Pages 最新构建状态，再核对自定义域名的 HTML、CSS、脚本和图片；缓存未更新时不要把“推送成功”当作“线上已更新”。
5. 同时提交应用仓库里的 Website 修改与验收记录。发布应用到 App Store 是另一项操作；官网更新不等于应用上架。

## 2026-10-23 内容与素材

- 商店公开版本经 Apple 查询接口核对为 1.4.0，应用最低系统 iOS 17。当前开发版本为 1.11.0（4）；1.5—1.11 的新增能力明确标注为开发版，没有虚构公开测试下载入口。
- 首页使用浅色、石墨灰与系统蓝，播放展示区为深色；更新、帮助与隐私页共用同一导航与文字层级。静态站不加载第三方字体、广告或行为分析脚本。
- 海岸与雪山来自仓库已有的原创 AI 设计素材，来源见 `Design/ASSETS.md`。海报中的名称和时长是界面示意，不是内置影视资源。
- 功能截图来自原创测试片库：1.10.0 的时间选片／私人频道、1.11.0 的内容地图、1.9.0 的原生播放界面。未使用用户私人片库或影视剧画面。
- App 图标沿用现有品牌，展示图仅作网页编码和尺寸优化。没有把测试日志、视频、账号或内部诊断发布到网站目录。

本次结果见 `Docs/Testing/Website-2026-10-23/README.md`。初期浏览器工具返回 Work 设置禁用，不能用静态检查冒充视觉验收；最终状态以该记录为准。
