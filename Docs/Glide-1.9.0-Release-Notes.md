# Glide 1.9.0

## 此版本的新增内容

- 新增字幕全文列表，支持搜索台词、跟随当前句，点击即可跳到对应画面。
- 新增单句重播，从句首播放到句尾后自动暂停。
- 新增 A–B 片段循环，可设置起止点，沿用当前倍速反复观看。
- 新增两路外部字幕样式设置，分别调整字号、颜色和描边，支持背景透明度、实时预览及恢复默认。
- 字幕定位计算已设置的时间偏移；循环期间协调片头片尾跳过和自动下一条，切换视频时清除区间。
- 修复部分 Jellyfin 4K HDR 视频因字幕协商导致的播放失败；支持客户端显示服务器文字字幕，并恢复播放失败后的原画兼容入口。
- 恢复播放中的完整服务器字幕列表与可选数量，支持中英文及同语言多版本切换、关闭后重新启用，并记住手动选择；Jellyfin 文字字幕切换保留当前视频会话。
- 修复 Jellyfin 默认字幕单独传输且视频地址未包含字幕编号时不自动显示的问题，兼容未标注语言的默认轨道，并保留手动关闭字幕的选择。

- 新增 Jellyfin PGS 图形字幕的客户端显示，切换 PGS 保留视频流，无需通过视频烧录显示；支持关闭、重新启用和记住轨道选择。
- 恢复播放中的完整服务器音轨列表与数量，切换音轨保留当前进度、播放或暂停状态和字幕选择。

- 外观支持跟随系统、浅色与深色，采用系统蓝及原生分组表单，播放器保持深色。
- 简化片库导航和底部入口，将链接与固定目录集中到“更多”，减少重复操作入口。
- 调整密集媒体网格的懒加载结构，保留竖版预览及返回后的浏览位置。
