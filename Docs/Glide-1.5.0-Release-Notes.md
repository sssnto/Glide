# Glide 1.5.0 发布说明（验收稿）

状态：功能已接入，模拟器压力测试与 iPhone 到自建 Samba／WebDAV 服务的局域网验证已通过。最终界面回归、品牌 NAS 和实体 iPad 等缺项以验收记录为准。以下文案供验收通过后使用，尚未提交审核或发布。

## 此版本的新增内容

打开 NAS，接着看。

- 新增 SMB 2/3 连接：通过 NAS 地址和共享目录，直接浏览、播放自己的视频，支持账号登录及服务器允许的访客访问。
- NAS 连续观看：竖版媒体与目录预览，进入默认查看媒体；搜索、排序、收藏、固定目录及顺序／随机连播沿用熟悉的操作。
- SMB 兼容播放：按需读取 MP4、MKV 等已支持的视频，可切换音轨、内嵌字幕和倍速；实际可播放格式取决于编码及设备。
- 可选断点续播：在 SMB／WebDAV 来源中开启「记住播放进度」，重开视频继续观看；默认保留家庭视频从头刷看的习惯。
- 连接反馈更清楚：支持连接测试、重新登录，以及认证、权限、文件缺失和超时提示。
- 保留 WebDAV、Jellyfin、本地导入与离线播放入口，并完成相应回归。

## 本次边界

SMB 为只读访问，首次版本手动填写共享目录，不提供服务器发现、共享自动枚举或远端文件管理。SMB 入口使用兼容播放器，不承诺 PiP／AirPlay。WebDAV 沿用系统播放器与 HTTP Range 读取，格式支持与 SMB 入口不同。

外挂字幕同名自动匹配及视频级字幕记忆安排在 1.5.1；本版保留既有手动外挂字幕和内嵌字幕选择。不将这些后续能力写入 1.5.0 商店文案。
