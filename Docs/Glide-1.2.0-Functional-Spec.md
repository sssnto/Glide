# Glide 1.2.0：本地视频首批交付

日期：2026-10-15。开发构建：1.2.0（1），未发布。

按 SenPlayer 长期路线开始实施。本构建先交付可独立使用的本地观看闭环；M1 与 M2 仍有后续工作，不代表两阶段整体完成。按用户最新决定，WebDAV 暂不扩展。

## 用户可以做什么

1. 在「媒体来源」中批量选择视频，复制到「导入的视频」。重复文件名自动编号；读取失败的整批选择不会发布部分文件。导入过程中显示状态并阻止关闭来源页。
2. 选择「添加本地目录」，保存系统授权，不复制原目录。支持逐层浏览、范围内递归视频列表、搜索、收藏、固定目录及顺序／随机刷看。
3. 重启后恢复选中的来源和目录。视频身份使用来源 UUID 与相对路径，收藏不依赖设备沙盒的绝对位置。
4. 显示本地视频生成的封面；播放本地资源时拖动时间轴，显示定位缩略图，松开后执行定位。
5. 长按导入副本，选择「删除导入的视频」，确认后删除 Glide 内副本及对应本机收藏、记录。授权目录中的原文件不提供删除入口。
6. 在来源页对授权目录重新授权或移除来源。无法读取时显示错误，不把失败的扫描当作完整播放队列。

目录刷看继续从头播放、不写入观看历史；本地收藏可以在「继续与收藏」中的「我的收藏」重新播放。

## 本批实现边界

- 使用 AVPlayer 原生能力，优先 MP4／MOV／M4V。文件可被枚举不等于其中的编码可播放；本批不宣称 MKV／AVI 全格式兼容。
- 文件选择来自系统「文件」入口。iCloud／第三方文件提供方的离线可用性、长时间读取和授权恢复仍须真机验证。本批没有相册导入。
- 时间轴预览仅限本地资源（包含已有离线资源与演示视频），180 ms 防抖、两秒一个请求位置、单张最大 336 × 188；取消旧请求，生成失败显示占位。未实现远程故事板或持久缩略图磁盘缓存。
- 本地封面最多同时生成两张，内存缓存上限 24 MB；不在首帧前扫描所有视频生成缩略图。
- 只读遍历授权范围，跳过隐藏文件、链接和包；本地路径独立处理系统规范化与链接边界。
- 不加入 SMB／FTP、兼容解码内核、分段磁盘缓存或云同步。WebDAV 本轮不新增能力。

## 数据和兼容

新增来源能力描述与文件目录提供方接口。Jellyfin 目录继续使用媒体库 API，WebDAV 保留原有适配行为，避免把不同服务强行套入同一种目录语义。

来源、目录偏好、固定目录、收藏、进度和剧集索引改用带 schema 的本机 JSON 快照。写入采用原子替换，并保留上一份可解码备份。首次迁移校验读回值，旧 UserDefaults 记录保留；损坏主文件尝试备份，未知未来 schema 阻止降级覆盖；无法恢复或保存时在设置中显示状态。来源选择、目录位置等轻量偏好仍使用 UserDefaults，密码和 token 继续存放钥匙串。

导入在后台分批协调读取，先暂存完整选择再移入片库；新来源保存失败会清理本次新建目录。删除副本先在同目录改名，保存匹配的片库变更失败时移回原处，再清理副本。突然终止进程仍可能留下隐藏暂存文件，这不等同于跨文件系统事务。

## 接下来按版本推进

| 版本工作包 | 目标 | 进入下一包的条件 |
| --- | --- | --- |
| 1.2.0 首批（本构建） | 本地导入／目录、稳定身份、快照恢复、本地时间轴预览 | 核心测试、编译与本地闭环界面回归通过；真机验收后决定发布 |
| 1.2.x | 补 M0 实测、兼容内核样片验证、明确播放内核接口；本地授权／大目录真机修订 | 候选方案有格式、字幕、功耗、许可及系统输出记录，不提前承诺全格式 |
| 1.3 | SMB／FTP、兼容播放、基础跳过、缓存与系统控制，分小版本验收 | 每个协议与内核独立完成连接、定位、轨道、取消及重启回归 |
| 1.4 及以后 | 媒体服务器、云盘／IPTV、字幕弹幕、同步隐私、多平台 | 继续按 SenPlayer 路线 M3–M8 推进 |

上述为工作顺序，具体发布日期随各包验收确定。WebDAV 暂不占用后续版本新增功能额度；收费继续暂缓。
