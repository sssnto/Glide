# 视频文件大小排序

日期：2026-11-16。

- 视频排序增加“文件大小：从大到小”和“文件大小：从小到大”，列表显示对应文件大小。
- 覆盖 Jellyfin / Emby 家庭视频、WebDAV、SMB 和本地视频；电影片库增加“文件大小”并沿用升降序切换。节目合集不是单个文件，不显示该选项。
- 始终将未知、无效大小放在末尾，同大小按名称和稳定 ID 排列。使用 Int64 字节值，保留大文件精度；不根据码率估算。
- Jellyfin / Emby 大小排序分页读取完整当前范围的元数据，然后统一排序；顺序播放和搜索结果使用相同顺序。Jellyfin 的 [官方排序字段](https://typescript-sdk.jellyfin.org/variables/generated-client.ItemSortBy.html) 没有文件大小，因此不向服务器发送不受支持的 `SortBy=Size`。
- 首次整理读取元数据时显示进度；离开范围或更改查询后丢弃旧结果。只读取列表、文件大小和现有预览，不下载视频内容。完成后单纯切换大小升降序复用已读取的列表。
- 大小来自默认／第一播放版本，不合计多个替代版本。WebDAV 使用 PROPFIND 的 `getcontentlength`，SMB 使用目录已有的 size，本地来源使用目录资源属性；不逐视频发 HEAD 或解析整个文件。
- 旧 WebDAV 缓存继续用于原有浏览。第一次按大小排序时，仅对缺少新版大小元数据标记的目录重新读取；新版缓存即使服务器没有返回大小也能复用，避免不断重扫。
- 排序设置继续按目录保存，并可用于固定目录。

Jellyfin 连接异常仍是独立待核对问题，需要用户反馈具体错误；此次排序未改动生产登录或连接权限。

验证材料：`Testing/File-Size-Sort-2026-11-16/`。仅使用本机隔离服务和原创样例，不改动用户 NAS。
