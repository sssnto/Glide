# Glide 全局界面与交互改版

本文件记录 0.3.0 本地改版的产品规则。当前收费方案暂缓；所有已实现能力直接可用。电影、节目是“先选作品再观看”，家庭视频和照片是“按目录刷看”，两条路径共用片库入口但不混淆播放预期。

iPhone 模拟器的离线演示首页见 [改版预览](../Design/native-redesign-home-2026-09-23.png)。

## 信息架构

| 一级位置 | 用户要完成的事 | 主要动作 |
|---|---|---|
| 片库 | 选择来源、媒体库或目录，找到作品 | 切换来源、搜索/排序、进入作品或刷当前范围 |
| 继续与收藏 | 回到上次内容，管理本机记录 | 继续播放、取消收藏、移除历史 |
| 离线 | 查看和管理已下载文件 | 暂停/继续/删除下载、离线播放 |
| 设置 | 调整播放偏好和寻求帮助 | 音轨/字幕偏好、诊断、隐私与支持 |

iPhone 使用系统底部标签；iPad 继续使用侧栏和详情区。媒体来源从片库页顶部进入，不另占一个一级标签。进入电影/节目媒体库后保留返回“媒体库”的明确路径；家庭媒体仍显示目录层级和范围操作。

## 内容页与观看路径

- **电影与节目墙**：顶部只呈现媒体库名称、作品数量与排序；海报网格承载发现，点海报进入详情。详情首屏以海报、片名、年份/评分/时长和播放动作建立主次。电影可先选声音、字幕与画质；节目把“季与集”移到简介和演职人员之前，缩短选集路径。
- **家庭媒体**：目录使用纵向懒加载的封面网格；图片完整展示，目录名仅在图片下方出现一次，不叠加大标题和重复的操作提示。Jellyfin 优先展示目录自己的主图，否则寻找目录内最近的视频海报。WebDAV 展示目录中的封面文件或首张图片；没有可用图片时保留清晰的目录占位。目录、包含子目录的范围、名称/添加时间排序、顺序/随机队列与“刷本目录”放在同一上下文。点单个封面从该条进入当前范围队列；顺序播放沿用列表排序，左右滑动只在该类队列切换。Jellyfin 的添加时间取媒体 `DateCreated`；WebDAV 优先取创建时间，其次取最后修改时间，均未提供的文件排在末尾。电影与节目不通过横滑跳到无关作品。
- **播放器**：视频画面优先；顶部为退出、片名、锁定和更多，底部为进度与紧凑播放控制。常用画质单独呼出选择；音轨、字幕、画中画、AirPlay、速度和诊断集中在可滚动的“播放设置”半屏/全屏面板。设置打开时停止自动隐藏控制，完成或下拉后继续计时。
- **来源连接**：协议选择、地址与凭据在表单中填写；主按钮固定在安全区域底部，连接中禁重复提交。连接失败保留非敏感输入并显示错误；片库加载失败可直达媒体源管理。
- **个人与离线**：个人页通过“继续观看 / 我的收藏”切换，卡片保留进度和来源，左滑可移除本机记录。离线页以封面、状态、进度和主操作组成单条任务；下载限制放在列表末尾，不挡住影片。首页底部留出滚动空间，最后一排封面可滑到系统标签栏上方。

## 视觉与状态规则

采用深色中性背景、薄荷绿作为单一主动作色。海报保持 2:3，单集画面保持 16:9；标题可换行，评分和时长是辅助信息。内容区以 20–24 pt 左右边距、16–26 pt 网格间距、44 pt 最小可点区域为基准；动态字体下优先换行和纵向排列，不让字幕/音轨名称覆盖控件。播放器覆盖层只在显式唤出时出现。

加载期间保留已显示的媒体；空库说明下一步；连接失效给重试和管理来源；下载、转码、诊断错误必须可恢复。固定目录、搜索和排序在当前来源/范围内生效。任何移除本机记录的动作都不暗示删除服务器上的媒体。

## 本轮验证与下一步

本轮改动已通过 iOS Release 和 iPhone 模拟器 Debug 构建；模拟器 `testCompactPlayerControls`、`testStageSettingsAndDiagnostics`、`testAddSourceValidation` 通过。电影/节目与家庭目录应继续在真实 Jellyfin 大库上核验：首屏海报加载、季/集切换、动态字体、VoiceOver、iPad 分屏、横屏播放器、长音轨/字幕名称与弱网恢复。当前本地改版尚未上传 TestFlight。
