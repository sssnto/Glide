# 阶段三交付与发布门槛

## 已实现的本地能力

- StoreKit 2 非消耗型产品 `com.songpeng.glide.pro.lifetime` 的源码已准备，但当前构建不包含购买页面或 StoreKit 服务。App Store Connect 商品（Apple ID `6815111578`）保留为“准备提交”，不随当前免费版本送审；其 ¥18.00 定价只是暂存方案，不代表最终商业策略。
- Pro 候选权益：新建离线下载、首选语言/强制字幕/字幕大小、快进间隔/控制栏时长、Wi-Fi 下载与容量设置。基础播放、兼容恢复、续播、播放期内轨道选择继续免费。已有离线文件不因退款或状态失效而自动删除。
- 根据 2026-09-23 的产品决定，收费内容暂缓。0.3.0 的 Debug 与 Release 均无收费入口或权益门槛；离线下载与播放个性化继续免费。StoreKit 源码留存供以后重新设计权益，但不参与当前构建。
- 应用内数据与隐私说明、支持邮箱；静态隐私与支持站点源码位于 `Website`，已发布到 `sssnto/glide-privacy` 仓库。GitHub Pages 主分支已启用，域名 DNS 和 HTTPS 状态需单独确认。

## 发布前不可跳过

1. 当前免费版本无商品审核截图或交易测试要求。日后重新启用收费时，再检查 Paid Applications Agreement、税务、收款条件、销售地区和审核截图。
2. 日后重新启用收费时，使用 Xcode StoreKit 或沙盒测试阶段三计划 P02–P08，尤其是退款/撤销、待批准和重装恢复。
3. 用户已完成 `glide.sssnto.cn` 的 HTTPS 证书配置；2026-09-23 已在浏览器核验更新后的 `/privacy.html` 和 `/support.html` 均正常打开，且不再包含购买说明。
4. 将站点 URL 填到 App Store Connect 隐私政策与支持 URL；核对 App Privacy 问卷、PrivacyInfo.xcprivacy、实际代码存储与网络请求一致。
5. 公开发布当前免费版本时，复跑播放、离线、设置和支持路径；补齐用户支持与媒体版权审核演示素材。将来决定收费权益后，单独开展商品展示、购买恢复和交易测试。
6. 每次发布固定记录归档版本、上传构建、TestFlight 群组和审核状态，不把本地构建当已发布版本。

## 仍需取舍

- 大库索引/历史的版本化数据库迁移、下一片受限预取、更多格式内核和全机型性能矩阵尚未完成；商业承诺需与已测支持范围一致。
- TestFlight 小范围外部测试可在交易及支持路径稳定后开始；未经用户同意不建立公开邀请链接或扩散到陌生测试者。
