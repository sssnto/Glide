# Glide 1.14.0：精彩片段集

发布文案草稿，尚未上传商店。

## 此版本的新增内容

- 收藏视频里喜欢的那一段：选择起点与终点，预览后保存。
- 把不同视频的精彩部分组合成合集，按喜欢的顺序连续刷看。
- 为合集选择封面，搜索、重命名和整理片段，退出后接着刷。
- 从片段进入完整视频，返回后继续浏览；片段进度与正片续播分别保存。
- 已下载本机文件的片段可以离线回看，播放前核对原文件版本。

片段集保存时间范围及文件引用，不修改源视频。跨文件切换可能需要加载；不包含片段视频导出或自动剪辑。实际支持范围与验收见 [1.14.0 记录](Testing/Glide-1.14.0/README.md)。
