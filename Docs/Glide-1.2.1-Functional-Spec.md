# Glide 1.2.1：播放内核接口与格式检查

日期：2026-10-15。开发版本 1.2.1（1），未发布。延续用户已验收的 1.2.0 本地来源首批功能，WebDAV 暂缓扩展。

## 用户可见变化

本地文件的「播放设置 → 视频信息」展示实际读取的文件头类型、视频／音频编码、轨道数量与系统可播放性检查。检查读取最多 4096 字节头部，容器提示不依赖扩展名；其余元数据由 AVFoundation 异步读取。无法读取时显示未完成检查，不把缺失信息判为“不支持”。

损坏／不兼容文件保留重试与播放诊断入口；纯音频文件提示没有视频轨道。系统判定可尝试播放，不代表已经解码画面。失败提示不由扩展名预先拦截；Jellyfin 的本地下载兼容回退继续由现有恢复策略处理。

详情页的「从头播放」把起播位置随本次播放请求传入，避免独立视图状态导致旧续播位置被复用；节目已看完后的从头观看采用同样机制。

脱敏播放诊断 schema 更新为 6，增加 `localMedia`，仅包含封装枚举、轨道数量、可播放性与经过 token 过滤的编码名；没有新增文件名、路径、URL 或授权数据。

## 工程变化与验证范围

- `PlaybackEngine` 统一播放控制、定位、时钟、状态、轨道、首帧、预览和资源释放；原生实现为 `NativePlaybackEngine`。
- `PlaybackTrack` 使用内核无关 ID、名称和语言；视图不再持有 AVMediaSelectionOption。
- 本地时间轴预览通过内核异步提供；继续限制为本地，保留取消、去抖和原布局。
- AVPlayerItem、原生输出检查、鉴权 asset loader、KVO、seek 失效控制收进适配器。显示层和画中画在明确的原生边界连接。
- 控制器保留 Jellyfin 恢复、缓冲策略、保存／上报、用户暂停意图和会话身份。
- 固定开发验证目录及启动参数仅存在于 DEBUG 模拟器构建；样例不进入应用资源包。

新增核心测试覆盖旧装载／旧 seek 失效、签名与截断容错、未知检查与纯音频／不可播放的区别。界面回归覆盖格式样例、轨道选择、重开、预热、本地时间轴和服务器恢复。实际结果见 [测试记录](Testing/Glide-1.2.1-播放内核与格式验证-2026-10-15.md)。

## 后续版本顺序

本包完成 M1 中播放内核接口这一部分，并建立 M0 原生格式基线；M0／M1／M2 尚未整体完成。下一包先做固定候选的兼容内核独立验证与真机授权／性能回归，通过后分批接入兼容播放、SMB／FTP、跳过等 1.3 工作。不能把本包视为已经支持第三方内核、全部格式或完整 SenPlayer 能力。
