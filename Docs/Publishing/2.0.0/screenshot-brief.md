# 2.0 截图文案与选图

1. **常用的事，各就各位**：观看页，继续观看与找片入口；参考 00-Clean-Preview。
2. **认出作品，再点播放**：片库，标题、季集、片长和来源；参考 02-Library-Light。
3. **喜欢的视频与片段，随时回来**：收藏、时刻和精彩片段；参考 03-Collection-Light。
4. **看着预览，直接勾选**：原视频网格多选及底部操作；参考 14-Original-Grid-Selection。
5. **进度清楚，整理从容**：任务的已保存、待处理与需核对；参考 11-Active-Rotation-Task 与 12-Task-Needs-Attention。
6. **画面优先，控制顺手**：实际播放器，倍速、音轨、字幕与方向控制；参考 06-Player-Light。
