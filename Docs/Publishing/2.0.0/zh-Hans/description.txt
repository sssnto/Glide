Glide 是 iPhone 与 iPad 上的私人媒体播放器。连接自己的本地视频、Jellyfin、Emby 与 NAS，把找片、观看、离线和整理放在一起。

2.0 全新工作台
观看、片库、收藏、任务，四个清晰入口。继续观看优先出现，作品名、季集、片长和来源分层展示。外观跟随系统，支持浅色、深色与大字号布局。

找到现在想看的
跨 Jellyfin、Emby、本地与已下载内容统一搜索，选择来源和文件版本。按可用时间和剩余片长挑选下一部；把电影、剧集或视频目录编成自己的频道，剧集保留季集顺序。

打开自己的片库
导入视频文件，或授权访问本地原目录。连接 Jellyfin、Emby、SMB 2/3 与 WebDAV，浏览电影、剧集和家庭视频；支持 HTTP(S) 视频地址与 STRM 链接文件。家庭视频和目录采用竖版预览，搜索、范围、排序与播放顺序集中处理。

留住喜欢的片段
收藏视频，按缩略图和章节找回位置，把某一刻命名保存。截取起止区间，跨视频组合精彩片段集，按自己的顺序连续回看。内容地图依赖系统可解码的本地／离线文件，或 Jellyfin 已生成的 Trickplay。

没有网络，也能接着看
管理离线下载，按时间和容量准备随身行程，打包接下来的剧集。完成后做出发前离线检查，再在断网环境中播放、切换和续播。离线可用范围取决于来源、格式及详情页的操作。

把方向整理好
在当前视频预览方向并保存；Jellyfin 可在原视频网格勾选批量旋转，任务集中显示已保存、待处理与需核对数量。配套插件在自己的服务器逐个处理，无需把大视频传到手机。可写 WebDAV 提供下载处理后回传、备份与还原。
方向保存目前覆盖符合条件的 MP4／MOV／M4V。Jellyfin 需安装匹配服务器版本的 Glide Toolkit 1.1.0+ 并授予写入权限；WebDAV 需通过安全替换检查并预留处理空间。

专注播放本身
系统与兼容播放路线，播放中选择音轨、字幕与倍速，双指缩放画面。支持双外部字幕、ASS／SSA 原始字体、颜色、排版和特效，以及具备服务器提取条件的 Jellyfin PGS；提供文本字幕定位、单句重播与 A–B 循环。原字体需要实际提供，外部字幕层不随 PiP／AirPlay 输出。

私人媒体，保持私人
无需 Glide 账号。登录凭据保存在系统钥匙串，媒体直接来自你选择的来源。方向处理发生在设备或你自己的服务器，原视频不会上传至 Glide 运营的服务器。

Glide 不提供影视片源或在线字幕搜索，请使用有权访问的视频、服务器和字幕。实际播放能力取决于设备、文件与来源。
