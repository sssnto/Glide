# Glide 2.0.1 发布文案

## App Store「此版本的新增内容」

为 iPhone Duo 优化，展开精彩，观看更自在。

- 适配 Duo 内外屏、展开折叠及横竖屏布局，浏览与播放操作更顺手。
- 展开后默认全屏观看，控制器支持轻点显隐和自动收起，也可手动打开控制面板。
- 优化片库在屏幕空间变化和返回前台后的排布，修复海报、文字被系统栏遮挡的问题。
- 新增播放器主界面的画中画快捷入口，方便边看视频边使用其他 App。
- 修复画中画返回桌面后可能意外中断或暂停的问题。
- 修复部分 Jellyfin 服务器新增连接时无法登录的问题，改善播放稳定性。

## App Store 宣传文本

为 iPhone Duo 优化。展开大屏，沉浸观看；合上手机，操作依旧熟悉。片库随屏幕灵活排布，画中画让精彩陪你切换 App。

## 社交平台发布文案
