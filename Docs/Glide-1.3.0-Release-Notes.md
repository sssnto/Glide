# 1.3.0 发布文案草稿

开发版本，尚未发布；对外使用前核对最终验收范围。

**此版本的新增内容**

- 新增本地兼容播放，可在播放设置中切换播放器，播放更多本地视频格式。
- 系统播放失败时，可直接尝试兼容播放。
- 兼容播放支持已验证的内嵌 ASS 字幕与多音轨选择。
- 修复部分本地视频的中文字幕显示为方框的问题，内置离线中文后备字体。
- 新增 Jellyfin 原画兼容传输：4K／高码率视频在服务器支持时优先使用原画分段供流，保留视频画质与播放位置，减少手动切换。
- 修复部分 Jellyfin 视频未能启用原画兼容、失败后重试入口消失的问题，补充当前传输状态提示。
- 离线副本可直接切回在线播放，保留已下载文件；补充网络缓冲诊断并限制无效等待的重复触发。
- 切换播放器保留播放位置与暂停状态，连续刷看更方便。
- 改进进度拖动和播放状态显示，新增播放器诊断信息，优化退出与重开时的资源清理。

不同文件、编码和设备的播放效果可能不同；兼容播放暂限本地文件，画中画与 AirPlay 请使用系统播放。
