# WebDAV 播放交互与目录封面 · 构建 7

## 当前视频内修正方向

播放设置中的“视频方向与保存”打开播放器底部控制区。左右旋转直接作用于当前播放画面，保持原来的媒体、解码器和播放层，不要求输入连接、重新选择目录、下载或解析整个视频后才预览。原播放器控件保持正常方向，画面内的 ASS 与视频同步旋转；普通文字字幕保持可读方向。

“保存到当前视频原文件”自动使用当前 WebDAV 来源与实际播放的文件地址。确认后才读取原文件、校验保护、上传校验、备份并替换，完成后保留进度、暂停／播放状态、音轨选择及倍速重新打开。重新读取已保存的文件时，临时旋转归零，避免双重旋转。当前会话可从备份还原，底层恢复记录继续持久保存。

入口仅在当前直接播放的 WebDAV MP4／MOV／M4V 文件上显示。Jellyfin、Emby、SMB、本地／离线副本、STRM、画中画与外部播放不提供原文件保存入口。临时方向不传递给 AirPlay 或画中画，旋转期间禁用这两个入口；用户可以保存方向后再使用。写入中停用播放导航和关闭手势，防止切换视频造成保存对象混淆。

旧的独立方向验证工具保留为 DEBUG 验收入口，正常播放器不再打开路径选择工具。此调整不扩展原文件写入支持格式或放宽覆盖保护。

## 目录自动继承封面

WebDAV 目录优先使用 folder／cover／poster／thumb 图片；没有时选取目录内的视频帧，目录内只有目录时向下寻找视频，使上层目录继承子目录的封面。首个候选无法解码时尝试其他候选，空目录保留占位图。

封面候选优先读取持久目录索引，缺失时仅按需查询。遍历限制 32 个目录、12 层、3 个候选；最多同时执行两个目录封面任务和两个视频帧解码任务，图片最长边 640 像素、单次生成有超时。缩略图以来源／账号／文件／修改时间隔离缓存到本机，滚动重进时复用；不先把视频下载到本地副本，也不批量生成所有视频的缩略图。取帧使用流式分段请求，实际传输量取决于容器索引位置和服务器 Range 支持，不能据此承诺固定流量上限。

文件保存后清理对应来源媒体缓存并更新目录封面的请求版本，手动刷新目录后重新选择候选。保留原有竖版目录卡片与图片比例，控制信息仍使用系统配色和组件。
