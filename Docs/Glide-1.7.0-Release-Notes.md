# Glide 1.7.0

## 此版本的新增内容

- 新增 Emby 直连，浏览电影、剧集与家庭视频媒体库。
- 支持 Emby 影片详情、季集浏览、范围搜索及分页加载。
- 接入原文件播放、服务器 HLS、音轨与字幕选择，以及服务器观看进度同步。
- Emby 可使用现有收藏、离线下载、导入字幕和节目片头片尾规则。
- 改善添加来源时的键盘切换，方便连续填写地址与账号。
- Emby 原画兼容流定位偏差超出容差时，在原文件已验证可播且无需服务器选轨的条件下自动恢复位置，并保留播放或暂停状态。

## 内部发布边界

本文件是开发版本材料，未提交商店。实施与验收见 [版本计划](Glide-1.7.0-Product-Plan-2026-10-20.md)及 [验收记录](Testing/Glide-1.7.0/README.md)。

保留 Emby 4.9.3.0 测试期间的 HLS 定位偏差记录：目标 24 秒，实际约 28.4 秒。同一文件在新建媒体记录中复测可准确定位，服务端索引／时间轴差异的完整根因尚未确认。客户端已增加有条件、每次兼容尝试最多一次的原文件恢复保护；真实解码验证与注入偏差的控制器契约分别记录，不将契约当作所有真实影片组合均已通过。

本版不包含 Plex、飞牛、Emby 自动片头检测、直播、云盘及全格式／全 HDR 组合验收。离线下载沿用默认媒体版本的 MP4／MOV／M4V 原文件范围。
