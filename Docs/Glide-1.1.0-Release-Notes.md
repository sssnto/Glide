# Glide 1.1.0 发布材料

本地构建：1.1.0（4）。发布说明草案，尚未归档上传或提交此版本至 App Store Connect。构建 2 的 HDR 修订已由用户确认测试完成并提交 GitHub；构建 3 的文件路径展示与缓冲策略已提交 GitHub。构建 4 修正缓冲恢复后过早转码，独立记录见[缓冲恢复验证](Testing/Glide-1.1.0-缓冲恢复验证-2026-10-10.md)。

## App Store「此版本的新内容」

这次更新让家庭刷看和追剧更连贯：

- 常用刷看可保存目录范围、排序和播放顺序，一键开始观看。
- 返回目录时恢复浏览位置，刷新期间保留已有内容。
- 继续观看按节目整理，自动找到当前集或下一未看集，支持跨季续播。
- 播放准备时显示视频预览，并提前准备下一段可直接播放的视频资源。
- 离线下载按队列进行，海报和影片信息可在离线时查看。
- 移除媒体来源时，可以选择保留已完成的离线影片。
- 改进 HDR 播放路线协商及不兼容色彩流的自动恢复。
- 视频信息支持查看和复制文件路径，远程播放按倍速和实际卡顿调整缓冲目标。
- 修正原画缓冲恢复后被过早切到转码的问题。

本次仍使用系统原生播放器，保留现有刷看、选集、倍速、缩放拖动与锁定操作。

## TestFlight「测试内容」

请重点验证常用刷看规则保存、返回后浏览位置、节目级继续观看、连续切片，以及离线下载暂停／继续、完成校验和断网播放。完整步骤见[用户验收计划 U01–U15](Testing/Glide-1.1.0-用户验收计划.md)。

构建 2 的[HDR 色彩复测步骤与结果](Testing/Glide-1.1.0-HDR-色彩回归.md)已记录，用户确认本轮测试完成。后续回归仍需核对默认自动播放颜色、声音／字幕改变、切集与拖动，异常时提供 schema 4 诊断。

播放异常请附上媒体名称、网络、设备与系统版本、重现步骤和应用内导出的播放诊断；不要提供服务器密码或令牌。
