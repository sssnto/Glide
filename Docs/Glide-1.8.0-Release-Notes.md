# Glide 1.8.0

## 此版本的新增内容

- 新增双字幕，同时显示两份外部 SRT／VTT 字幕。
- 主字幕和第二字幕可分别调整时间偏移，支持 0.1 秒微调与快速归零。
- 新增集中式字幕控制页，可选择同目录字幕、导入文件、调整第二字幕字号与底部距离。
- 分别记住两路字幕的选择、关闭状态和时间偏移，再次打开视频时恢复。
- 改善两路字幕同时加载时的导入副本保留与读取取消，减少重复设置。
- 改善兼容播放中连续暂停定位后的画面更新。

## 开发验证边界

本版材料尚未提交商店；实际结果见 [验收记录](Testing/Glide-1.8.0/README.md)。双字幕首批支持两份外部 UTF-8 SRT／VTT，不包含双内嵌字幕、外挂 ASS、在线字幕搜索，以及 PiP／AirPlay 外部字幕输出。

Plex 与飞牛影视按用户决定暂缓。1.7.0 的媒体服务器、4K／HDR 与长 GOP 定位边界继续保留。
