# Glide 1.13.0：统一片库

按用户确认落地：统一搜索 Jellyfin／Emby、本地授权视频及已下载内容，可靠作品标识聚合，明确来源与版本，复用频道和离线行程。苹果原生搜索、列表与导航，不新增底部页签。

## 用户流程

首页「搜索全部片库」或片库更多菜单进入。输入片名、节目或文件名，按类型及来源筛选。各远程来源独立分页、超时与返回，慢来源不阻塞其他结果；本地只扫描已授权目录，离线筛选不请求媒体服务器。

结果以作品卡展示。只有同类型、有效且一致的 TMDB／TVDB／IMDb 标识才聚合；优先级为 TMDB、TVDB、IMDb，不做跨提供方的猜测匹配。不同类型不合并，同名无 ID 各自保留；提供方标识互相冲突时拆开。同一条目的媒体版本与其离线副本保持独立播放入口。

进入作品页核验各来源当前版本，显示来源、可获取的分辨率／HDR／编码／大小和本机副本状态。选择后重新核对账号、条目与版本，记住上次成功选择；所选版本消失时提示重选，不能静默改播默认文件。远程条目已有其他版本下载时，不能覆盖用户本次明确选择。

节目先选择来源再进入原有季集页；各来源进度分别保留，不把不同剪辑版本的播放时间直接互套。可加入现有或新建私人频道，或带入离线行程确认页。频道沿用来源默认版本，离线行程沿用默认原文件下载限制，界面明确说明；不宣称这两个入口支持任意版本固定。

## 数据与性能

搜索缓存只存显示元数据、稳定身份与账号／地址绑定摘要，不存密码、令牌、解析后的播放 URL 或服务器文件路径。按需返回缓存，明确显示更新时间，播放前重新验证；不把缓存存在等同于来源在线。来源移除、换账号或换地址后，排除原缓存。已下载本机副本按用户所有权继续独立可用。

本地最多 500 个目录／5000 个视频，超限明确提示；不递归扫描 NAS。远程按 60 条请求，单来源单关键词最多约 6000 条，缓存最多 10000 条元数据。主线程外执行文件枚举、缓存读写、匹配与聚合；原生 List 每批展示 100 个结果，可继续显示或读取后续页。输入防抖 300 ms，旧查询不能覆盖新结果；下拉可重新索引本地目录。

## 验收

核心覆盖标识／冲突／同名、类型与来源、离线关联、版本选择、脱敏、数据量。使用原创视频和受控 JF／Emby 合约验证独立返回、失败、分页、取消、授权本地索引、账号变化、版本实际解码、旧下载隔离、频道与行程复用、离线搜索零联网。界面验证搜索 → 作品 → 版本 → 实际画面 → 重启记忆，以及搜索结果进入频道、行程与季集。真机、模拟器、合约和真实服务器结果分别记录，未执行项不记通过。

不含全 NAS 索引、自动刮削、Plex／飞牛新增接入或跨设备进度同步。网站继续以已发布 1.11.0 为准，1.13.0 尚未上传商店。
