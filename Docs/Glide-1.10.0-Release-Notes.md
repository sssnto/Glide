# Glide 1.10.0

## 此版本的新增内容

- 新增首页，集中展示继续观看、给我选一部和私人频道。
- 新增私人频道，把选定的媒体库、剧集、目录或单个视频编排在一起，多个来源可混排，剧集内部保留季集顺序。
- 支持查看本次编排、编辑频道内容和规则，排除已看完及最近开播的内容，并在本机保存频道；实际出现画面后才记入开播去重记录。
- 新增按时间选片，选择 20／45／90 分钟或自定义时间，结合内容类型与剩余片长挑选少量候选，展示推荐理由并直接续播。
- 选片和频道复用现有播放器，保留音轨、字幕、倍速和进度控制；观看结束后可返回原来的频道或选片页面。

## 支持范围

频道使用已连接且可访问的来源，属于客户端播放编排；每次准备有明确内容上限和结束位置。时间选片依赖可靠片长：支持媒体服务器返回的片长和按需读取的本地文件片长，未知片长会明确提示并排除。选择特定范围后才扫描内容，首页不自动遍历全部 NAS。

视频内容地图和画面分类仅完成独立的原创素材原型，本版不包含画面语义搜索功能。实际验证与未覆盖范围见 [1.10.0 验收记录](Testing/Glide-1.10.0/README.md)。本材料尚未提交商店。
