# Glide 1.11.0

## 此版本的新增内容

- 新增视频内容地图，按画面浏览视频，细看某个时间段，点击缩略图直接播放。
- 新增时刻收藏，保存并命名当前播放位置，从“我的”集中查看、搜索和再次打开。
- 新增章节导航，使用视频文件或来源提供的章节快速定位。
- 支持读取 Jellyfin 已生成的当前版本时间缩略图。
- 收藏与缓存绑定来源账号和文件版本；再次打开时校验版本，检测变化后提示重新确认。
- 优化手动时间定位，家庭视频关闭历史记录后，仍可按用户选择的位置起播。

## 范围说明

内容地图先覆盖系统可解码的本地、离线文件及已提供 Trickplay 的 Jellyfin。其他来源按实际能力提供章节与时刻收藏；不包含自然语言画面搜索。收藏使用本机独立存储，不包含跨设备同步。文件版本校验依据可获得的元数据，不等于全文件内容指纹。实际结果见 [验收记录](Testing/Glide-1.11.0/README.md)。尚未提交商店。

## 构建 2 修订

修复部分 ASS 字幕转换为文字字幕后，字体、颜色、描边和样式重置标签直接显示的问题。保留中英换行，避免将绘图坐标显示成对白；适用于应用的文字回退路线，未将其描述为完整 ASS 特效渲染。见[实际验证](Testing/Glide-1.11.0-ASS-2026-10-22/README.md)。

## 构建 3：ASS 原样渲染

- Jellyfin ASS／SSA 改用原脚本和 libass 绘制，保留字体、颜色、定位、描边、模糊、动画、绘图与卡拉 OK。
- 支持同目录及手动导入 UTF-8 ASS／SSA，原脚本与普通字幕全文索引分别处理。
- 读取当前媒体版本的字体附件；支持导入 TTF／OTF／TTC 字体，原字体缺失时提示，不将替代字形视为完整还原。
- 按实际解码时钟更新特效，保留时间偏移，字幕开关、ASS 与普通文字字幕切换不重开 Jellyfin 视频。
- ASS 使用原始布局，普通字幕字号、颜色和底部距离不覆盖原脚本。

构建 3 的开发验证与当时待验项目见[原样渲染历史记录](Testing/Glide-1.11.0-ASSStyle-2026-10-22/README.md)；后续真机结果见构建 4，尚未上传商店。

## 构建 4：原字体识别与实片验证

修复导入字体同时包含中文与英文名称时，中文字体名仍被误报缺失的问题。读取字体多语言名称，并在诊断中核对 libass 的实际字体选择。

已更新用户 iPhone 的 Glide，完成《绝望主妇》第一季第一集复核：该媒体没有字体附件，本次补入官方“文泉驿微米黑”原字体后，原字体缺失数为 0，确认 libass 实际选中该字体。原 ASS 配色、双语布局、暂停定位与字幕往返切换通过；动态效果另用原创脚本验证。其他片源需实际提供所用字体，仍支持从字幕控制导入。见[最终真机记录](Testing/Glide-1.11.0-ASSFont-2026-10-23/README.md)。
