# Glide 1.5.1 发布说明

本地构建版本为 1.5.1（2），未提交商店审核。实际验证结果及设备范围见文末验收记录。

## 此版本的新增内容

- 同名字幕自动匹配：播放本地目录或 SMB 视频时，识别同目录的 UTF-8 SRT/VTT 字幕。
- 多语言字幕选择：支持常见语言、简繁体和强制字幕后缀；多个候选可在播放页的字幕菜单中选择。
- 记住每个视频的字幕选择与延迟，再次打开时恢复，也可记住关闭状态或清除当前视频的字幕记忆。
- 手动导入字幕会保存本机副本，关闭后也可从字幕菜单重新启用。
- 本地／SMB 视频文件信息变化，或记住的字幕内容变化、丢失时，提供重新选择提示。

本版自动扫描范围为本地目录和 SMB。WebDAV、Jellyfin 延续手动导入入口。外挂 ASS、在线搜索、双字幕及画中画／AirPlay 中的外挂字幕另行规划。实际验证范围见 [验收记录](Testing/Glide-1.5.1/README.md)。
